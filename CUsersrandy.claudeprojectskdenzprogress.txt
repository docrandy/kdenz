
[2026-02-19 JSON Parse Error Fix Session]
Fixed critical Gemini API JSON parsing error that was causing pattern detection to fail.

ISSUE: Console error "SyntaxError: Unterminated string in JSON at position 197"
- Occurred in patternDetectionService.ts when Gemini returned JSON wrapped in markdown code blocks
- JSON was being cut off mid-response

ROOT CAUSE ANALYSIS:
- maxOutputTokens was 500, insufficient for full JSON response with multiple signals
- Gemini 2.5 Flash wraps JSON in ```json...``` markdown
- Prompt wasn't clear enough about expected JSON format (arrays vs objects)
- User text wasn't being escaped, potential prompt injection vector

FIXES APPLIED (commit 611ab9f):
1. Increased maxOutputTokens: 500 → 1000
   - Ensures complete JSON response without truncation
   
2. Improved prompt clarity
   - Changed JSON format example to show array-based structure
   - Removed markdown code block suggestion
   - Added explicit instruction: "Output JSON ONLY, no markdown code blocks"
   - Changed field names for clarity (signals array, patternNote string, etc.)
   
3. Added proper text escaping
   - Escape backslashes, quotes, newlines in user text
   - Prevents prompt injection vulnerabilities
   - Maintains data integrity when user input contains special characters
   
4. Enhanced debugging logging
   - Log raw response first 100 chars + length
   - Log extracted JSON first 100 chars + length
   - Better error messages for troubleshooting
