## 1. GLOBAL RULES (Apply to All Practice Modes)

### Session Flow Architecture
- Practice session page should ONLY contain the active session container
- Everything below the session container (transcript, metrics, analytics) belongs on a **separate post-session results page**
- Post-session page: navigate to dashboard OR "Try Again" / "Continue"

### Elements to Remove from Active Session View
- Word count display — remove entirely
- "Listening" indicator — remove (orb state communicates this)
- Filler words per minute metric — remove from real-time unless research-backed evidence supports it
- Text window that slides up from bottom — remove entirely

### Difficulty / Leveling System
- Do NOT let users choose difficulty upfront
- Start all users at baseline, level up automatically based on performance

---

## 2. MICROPHONE ORB (Start/Stop Control)

### Default State (Ready to Record)
- Shape: Circle/oval
- Color: **Neon green** (bright, vivid — not muted or pastel)
- Icon: **Microphone icon** centered inside
- Ambient effect/animation triggers on press

### Recording State (Active Session)
- Icon swaps from mic to **red square** (stop button)
- Ambient orb effect continues while recording

### Behavior
- Press orb → Start recording, icon changes to red stop square
- Press stop square → End recording, trigger post-session flow

## 4. PRACTICE MODE: LABELING EMOTIONS

### Entry Flow
- Click "Yes" on scenario → immediately enter Begin mode
- No intermediate screens, no task descriptions, no preamble
- Display ONLY what the person says
- Remove instructional text from active view

### Real-Time Feedback
- Analyze speech in real-time — do NOT wait for stop
- Fix: clicking "Analyze" currently removes transcript and shows only mic with no continue option

### Feedback Display After Label Attempt
- Correct label → thumbs up indicator
- "Make it Better" / "Pro Tip" button (optional press)
  - How to improve labeling
  - Pointer arrows to specific statement parts
  - Explanation of why that part matters

### Response Analysis Layout
- Lead with: thumbs up/down → "What did your response accomplish?" → suggestion
- Repetition detection: if same opening 3+ times → nudge with 2 alternatives

### Other Examples Section
- Show alternative responses to expand vocabulary

### Navigation
- "Try Again" (same scenario) and "Continue" (next scenario)
