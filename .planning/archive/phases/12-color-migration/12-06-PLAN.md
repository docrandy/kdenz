<migration_reference>
## Color Migration Mapping (apply to ALL files in this plan)

### Background replacements
- `bg-white` → `bg-background` (page-level) or `bg-background-surface` (card/panel)
- `bg-gray-50`, `bg-gray-100` → `bg-background-surface` or `bg-background-elevated`
- `bg-gray-200`, `bg-gray-300` → `bg-background-elevated`
- `bg-clinical-bg` → `bg-background`
- `bg-clinical-accent` → `bg-accent`
- `bg-black` → `bg-background` or `bg-accent` (contextual)

### Text replacements
- `text-gray-900`, `text-clinical-text`, `text-black` → `text-text`
- `text-gray-700`, `text-gray-600` → `text-text-muted`
- `text-gray-500`, `text-gray-400`, `text-clinical-muted` → `text-text-subtle`
- `text-white` (on dark bg) → `text-text`; (on accent bg) → `text-text-inverse`
- `text-clinical-accent` → `text-accent`

### Border replacements
- `border-gray-200`, `border-gray-300`, `border-clinical-border` → `border-background-elevated`
- `border-gray-100` → `border-background-surface`

### Status color replacements
- `text-red-*`, `bg-red-*` → `text-status-error`, `bg-status-error/10`
- `text-green-*`, `bg-green-*` → `text-status-success`, `bg-status-success/10`
- `text-blue-*`, `bg-blue-*` → `text-status-info`, `bg-status-info/10`
- `text-yellow-*`, `text-amber-*` → `text-status-warning`, `bg-status-warning/10`
- `text-emerald-*`, `bg-emerald-*` → `text-status-success`, `bg-status-success/10`
- `text-rose-*`, `bg-rose-*` → `text-status-error`, `bg-status-error/10`

### Interactive states
- `hover:bg-gray-50`, `hover:bg-gray-100` → `hover:bg-background-elevated`
- `hover:bg-gray-200` → `hover:bg-background-subtle`
- `focus:ring-blue-*` → `focus:ring-accent`
- `divide-gray-*` → `divide-background-elevated`

### Per CONTEXT decisions (features)
- Practice flow steps: step-indicator active = `bg-accent text-text-inverse`, inactive = `bg-background-elevated text-text-subtle`
- Scenario cards: `bg-background-surface border border-background-elevated`
- AI feedback sections: `bg-background-surface` with status-colored border-left for quality indication
- Pattern summary stats: status colors for ratings (good = status-success, needs-work = status-warning)
- Recording state: gold glow or `ring-accent` indicator
- Timer/progress: `bg-accent` fill on `bg-background-elevated` track
</migration_reference>
