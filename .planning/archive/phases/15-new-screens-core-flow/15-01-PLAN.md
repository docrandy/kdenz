**SlideTransition.tsx:**
A wrapper component that applies horizontal slide animations to route changes. Per user decision: "forward = slide left, back = slide right."

Implementation approach (CSS-based, no heavy animation library):
- Use React state to track transition direction (forward/back)
- Apply CSS classes for enter/exit animations:
  - `.slide-enter-left`: translateX(100%) -> translateX(0) (forward navigation)
  - `.slide-enter-right`: translateX(-100%) -> translateX(0) (back navigation)
- Duration: 250ms ease-out (Claude's discretion for smooth feel)
- Detect direction heuristic: maintain a simple route depth map (/ = 0, /practice/* = 1, /practice/results = 2) — deeper = forward, shallower = back
- Use `useLocation()` from react-router-dom to detect route changes
- Wrap children in a div with the appropriate animation class
