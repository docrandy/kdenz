```tsx
interface SegmentedControlProps {
  segments: string[];           // e.g., ["Coaching", "Analytics", "Transcript"]
  activeIndex: number;          // Currently active segment
  onChange: (index: number) => void;  // Called when segment changes
  className?: string;
}
```

**Visual design:**
- Container: rounded-full pill shape, `bg-background-elevated` background
- Each segment: equal width, centered text
- Active segment: `bg-accent` (gold) background with `text-text-inverse` (dark text on gold), rounded-full
- Inactive segments: transparent background, `text-text-muted`
- Transition: smooth 200ms background slide between segments
- Active indicator slides using CSS transform (not just color toggle) for premium feel

**Implementation:**
- Flexbox with equal-width segments
- Sliding gold background indicator positioned absolutely
- Transform: `translateX(${activeIndex * segmentWidth}%)`
- Touch-friendly: min-height 44px per segment
- Font: `text-body-sm font-medium`

**Swipeable panel support:**
The SegmentedControl only handles the tab bar. Swipe support for panels will be handled via touch events in the parent (PostSessionResults), similar to how CardCarousel works.
