  <name>Task 1: Create CardCarousel component</name>
  <files>src/components/CardCarousel.tsx</files>
  <action>
  Create a reusable `CardCarousel` component that displays children one at a time with navigation.

  **Props interface:**
  ```typescript
  interface CardCarouselProps {
    children: React.ReactNode[];  // Array of card elements
    className?: string;           // Optional wrapper class
    onSlideChange?: (index: number) => void;  // Optional callback
  }
  ```

  **Features:**

  1. **One card at a time:** Only the current card is visible. Cards take up the full available width with centered content and generous vertical padding.

  2. **Touch/swipe navigation (mobile):**
     - Track touch start X position on `onTouchStart`
     - Calculate delta on `onTouchEnd`
     - If delta > 50px, advance to next/prev card
     - Use `useState` for currentIndex, clamp between 0 and children.length - 1

  3. **Arrow buttons (all sizes):**
     - Left arrow: positioned on left side, vertically centered, semi-transparent background
     - Right arrow: positioned on right side, vertically centered
     - Hidden when at first/last card respectively
     - Style: `bg-background-elevated/60 hover:bg-background-elevated rounded-full w-10 h-10 flex items-center justify-center text-text-muted hover:text-text transition-colors`
     - Use simple SVG chevron icons (no library needed)

  4. **Dot indicators:**
     - Row of dots centered below the card
     - Current dot: `bg-accent w-2.5 h-2.5 rounded-full`
     - Other dots: `bg-background-elevated w-2 h-2 rounded-full`
     - Clickable — clicking a dot navigates to that card
     - Gap between dots: `gap-2`
     - Container: `flex items-center justify-center py-6`

  5. **Slide transitions:**
     - Use CSS `transform: translateX()` with `transition-transform duration-300 ease-out`
     - Container holds all children in a horizontal flex row
     - Only translate to show current card: `translateX(-${currentIndex * 100}%)`
     - Overflow hidden on the outer container

  **Layout structure:**
  ```
  <div className="relative overflow-hidden">
    {/* Slide container */}
    <div className="flex transition-transform duration-300 ease-out"
         style={{ transform: `translateX(-${currentIndex * 100}%)` }}>
      {children.map((child, i) => (
        <div key={i} className="w-full flex-shrink-0 px-4">
          {child}
        </div>
      ))}
    </div>

    {/* Left/Right arrows */}
    {/* Dot indicators */}
  </div>
  ```

  **Keyboard support:** Listen for ArrowLeft/ArrowRight keys when focused (add tabIndex={0} and onKeyDown handler).

  Export as named export: `export function CardCarousel(...)`.
  </action>

  </verify>
