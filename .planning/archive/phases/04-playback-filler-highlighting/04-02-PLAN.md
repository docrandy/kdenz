**Marker design per CONTEXT.md (needs evidence-based design):**
- Small vertical tick marks on the scrub bar at filler positions
- Color: use a muted red/coral (#EF4444 or similar) to stand out from teal progress
- Size: 8px tall, 3px wide
- Position: centered on the scrub bar track
- Hover state: slight scale-up and tooltip with filler type
- Tap/click: seeks audio to that timestamp

**Implementation:**
1. Calculate marker positions based on timestamp and duration:
```typescript
const markerPosition = (event.timestamp / 1000 / duration) * 100; // percentage
```

2. Render markers as absolutely positioned elements within the scrub bar container:
```tsx
{/* Filler markers */}
{fillerEvents?.map((event, index) => {
  const position = (event.timestamp / 1000 / duration) * 100;
  return (
    <button
      key={`filler-${index}`}
      className="absolute top-1/2 -translate-y-1/2 w-1 h-3 bg-red-400 rounded-full hover:scale-150 hover:bg-red-500 transition-transform cursor-pointer"
      style={{ left: `${position}%` }}
      onClick={(e) => {
        e.stopPropagation(); // Prevent scrub bar click
        handleSeekTo(event.timestamp / 1000);
      }}
      title={`${event.type} (${formatTime(event.timestamp / 1000)})`}
      aria-label={`Jump to ${event.type} at ${formatTime(event.timestamp / 1000)}`}
    />
  );
})}
```

3. Add handleSeekTo helper that accepts seconds directly:
```typescript
const handleSeekTo = (seconds: number) => {
  if (!audioRef.current) return;
  audioRef.current.currentTime = seconds;
};
```

4. Make the scrub bar container position: relative for absolute marker positioning.
