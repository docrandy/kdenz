<task type="auto">
  <name>Task 2: Wire consent modal into App.tsx first-run flow</name>
  <files>src/App.tsx</files>
  <action>
    Modify App.tsx to insert the consent modal into the first-run flow.

    **localStorage key:** `voicelab_consent_accepted` (value: `'true'`)

    **Current first-run flow in App.tsx:**
    1. Browser warning (non-Chrome)
    2. WelcomeScreen
    3. DiagnosticOnboarding
    4. Dashboard

    **New first-run flow (insert consent BEFORE welcome):**
    1. Browser warning (non-Chrome) — unchanged
    2. **ConsentModal** — NEW, gates everything
    3. WelcomeScreen — unchanged
    4. DiagnosticOnboarding — unchanged
    5. Dashboard — unchanged

    **Implementation:**
    1. Import ConsentModal at top of App.tsx
    2. Add a `CONSENT_ACCEPTED_KEY = 'voicelab_consent_accepted'` constant
    3. Add `showConsent` state variable (boolean)
    4. In the existing `useEffect` that checks onboarding state, add consent check FIRST:
       - Check `localStorage.getItem(CONSENT_ACCEPTED_KEY)` — if not set, `setShowConsent(true)`
       - Only proceed to check welcome/diagnostic if consent is already accepted
    5. Add `handleConsentAccept` function:
       - Sets `localStorage.setItem(CONSENT_ACCEPTED_KEY, 'true')`
       - Sets `showConsent(false)`
       - Then proceeds to check welcome state (if welcome not seen, show welcome)
    6. In `renderHome()`, add consent check AFTER browser warning but BEFORE welcome:
       ```
       if (showConsent) {
         return <ConsentModal onAccept={handleConsentAccept} />
       }
       ```

    **Important:** The consent modal should also apply to practice routes, not just the home route. A first-time user should not be able to navigate directly to `/practice/filler` without consent. Add a consent guard: if consent not accepted, redirect to home (where the modal will show). This can be done by checking `localStorage.getItem(CONSENT_ACCEPTED_KEY)` in the practice route wrappers and redirecting to `/` if not set.

    Or simpler: add consent state as a top-level check. If `!consentAccepted`, ALL routes render the ConsentModal. This prevents any route from being accessed without consent.

    **Chosen approach:** Top-level consent gate. In the App component's return, wrap the entire Routes in a consent check:
    ```
    if (!consentAccepted) {
      return <ConsentModal onAccept={handleConsentAccept} />
    }
    // ... existing Routes
    ```

    Where `consentAccepted` is a state initialized from localStorage in the useEffect.

    This is cleaner than per-route guards and ensures consent before ANY interaction.
