<objective>
Build the baseline session flow: the fixed 3-minute first session that captures a user's personal baseline metrics, and wire the complete first-run routing (consent -> baseline -> baseline results -> regular use).

Purpose: Personal baselining is the "gold standard" for voice coaching (eliminates bias from population comparisons). The first session MUST be a calibration session so all future sessions can show meaningful delta-from-baseline metrics. This is foundational to the core value proposition — users seeing their CHANGE, not arbitrary numbers.

Output: BaselineSession page with instructions, BaselineResults page with starting-point framing, updated PostSessionResults with baseline deltas, complete first-run routing.
</objective>

    - When user clicks "Begin Baseline", navigate to `/practice/baseline` route which renders PracticeSession with:

      - Duration passed via route state: `{ durationSeconds: 180, isBaseline: true }`

    **Update `src/components/PracticeSession.tsx`:**
    1. Read `isBaseline` from route state: `const isBaseline = (location.state as any)?.isBaseline ?? false;`
    2. In `handleStop`, if `isBaseline`:
       a. Calculate pause rate: `const pauseRate = silenceDuration > 0 ? (silenceDuration / 1000) / (elapsedTime / 60) : 0;` (rough approximation — pauses per minute based on total accumulated silence)
       b. Import `saveBaseline` from `src/services/baselineStorage.ts`
       c. Call `saveBaseline({ wpm, fillerRate: transcriptFillerRate, fillerCount: transcriptFillerCount, pauseRate, wordCount, durationSeconds: Math.round(elapsedTime), timestamp: Date.now() })`
       d. When saving to sessionStorage (the `voicelab_last_session` key), add `isBaseline: true` to the data
       e. Navigate to `/baseline/results` instead of `/practice/results`
    3. If NOT baseline, existing behavior unchanged (navigate to `/practice/results`)
    4. Add `is_baseline` to the sessionStorage data when saving session (so PostSessionResults can distinguish)

        - Duration: `3 min` — with "Baseline duration" label

       - This can be done by updating the PracticeCard onClick handlers in Dashboard, OR by adding a check in the PreSessionScreen that redirects to `/baseline` if no baseline exists
