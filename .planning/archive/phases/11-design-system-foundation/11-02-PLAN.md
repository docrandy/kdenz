<task type="auto">
  <name>Task 1: Add typography scale and spacing supplements to Tailwind config</name>
  <files>tailwind.config.js</files>
  <action>
Add a `fontSize` section under `theme.extend` in tailwind.config.js. These sizes match the prototype extraction documented in 11-RESEARCH.md.

```javascript
fontSize: {
  // Heading scale (Cormorant Garamond)
  'display': ['3rem', { lineHeight: '1.1', letterSpacing: '0.02em' }],       // 48px
  'h1': ['2.25rem', { lineHeight: '1.2', letterSpacing: '0.015em' }],        // 36px
  'h2': ['1.75rem', { lineHeight: '1.2', letterSpacing: '0.01em' }],         // 28px
  'h3': ['1.5rem', { lineHeight: '1.3', letterSpacing: '0.01em' }],          // 24px
  'h4': ['1.25rem', { lineHeight: '1.3', letterSpacing: '0.005em' }],        // 20px
  'h5': ['1.125rem', { lineHeight: '1.4' }],                                  // 18px
  // Body scale (Outfit)
  'body-lg': ['1.125rem', { lineHeight: '1.6' }],   // 18px
  'body': ['1rem', { lineHeight: '1.6' }],           // 16px
  'body-sm': ['0.875rem', { lineHeight: '1.5' }],    // 14px
  'caption': ['0.75rem', { lineHeight: '1.4' }],     // 12px
  'overline': ['0.6875rem', { lineHeight: '1.4', letterSpacing: '0.08em', fontWeight: '600' }],  // 11px
},
```

Place the `fontSize` block AFTER the `colors` block and BEFORE the `fontFamily` block in `theme.extend`.

The heading scale uses Cormorant Garamond (applied via base styles in Plan 01). The body scale uses Outfit. Letter-spacing on headings provides the premium serif feel documented in the prototype.

Do NOT modify any other part of tailwind.config.js. The colors, fontFamily, boxShadow, keyframes, and animation blocks from Plan 01 must remain exactly as they are.

**Add @layer components section:**

```css
@layer components {
  /* ===== BUTTON VARIANTS (Layer 3) ===== */

  .btn {
    @apply inline-flex items-center justify-center px-6 py-3
           font-body font-medium text-body
           rounded-lg transition-all duration-200
           focus:outline-none focus-visible:ring-2 focus-visible:ring-accent;
  }

  .btn-primary {
    @apply btn bg-accent text-text-inverse
           hover:bg-accent-hover active:scale-[0.98];
  }

  .btn-secondary {
    @apply btn bg-background-surface text-text
           border border-background-elevated
           hover:bg-background-elevated hover:border-accent/20;
  }

  .btn-ghost {
    @apply btn bg-transparent text-text-muted
           hover:bg-background-subtle hover:text-text;
  }

  /* ===== CARD VARIANTS ===== */

  .card-surface {
    @apply bg-background-surface rounded-xl
           border border-background-elevated
           p-6 transition-all duration-200;
  }

  .card-elevated {
    @apply bg-background-elevated rounded-xl
           border border-background-subtle
           p-6 shadow-md transition-all duration-200
           hover:border-accent/20;
  }

  /* ===== INPUT ===== */

  .input {
    @apply w-full px-4 py-3
           bg-background-surface text-text
           border border-background-elevated rounded-lg
```
