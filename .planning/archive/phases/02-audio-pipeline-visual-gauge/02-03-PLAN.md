**PostSessionResults page:**

Create a new page component at `src/pages/PostSessionResults.tsx`.

This page reads session data from sessionStorage (saved by PracticeSession on stop) and displays results.

```typescript
interface SessionResultData {
  durationSeconds: number;
  wordCount: number;
  wpm: number;
  fillerCount: number;
  fillerRate: number;
  focusMode: 'filler' | 'pace';
  transcript: string;
}
```

**Layout structure:**

1. **Header area:**
   - "Session Complete" title or similar
   - Checkmark icon or success indicator

2. **Templated summary paragraph:**
   - Locally generated (no AI), brief 1-2 sentences summarizing the session
   - Filler mode example: "You spoke for {duration} and used {fillerCount} filler words. {commentary based on count}."
     - 0 fillers: "Amazing — not a single filler word!"
     - 1-3 fillers: "Great job — minimal filler usage."
     - 4-7 fillers: "Good practice session. Keep working on awareness."
     - 8+: "Lots to work with! Awareness is the first step."
   - Pace mode example: "You spoke for {duration} at an average pace of {wpm} WPM. {commentary based on pace}."
     - < 100 WPM: "Your pace was on the slower side — try picking up a bit."
     - 100-150 WPM: "Great conversational pace!"
     - 151-180 WPM: "You were speaking fairly quickly — try slowing down."
     - > 180 WPM: "You were speaking quite fast. Practice pausing between thoughts."

3. **Key stats:**
   - Filler mode: filler count (large number) + session duration
   - Pace mode: average WPM (large number) + session duration
   - Style: large prominent numbers with labels below, centered

4. **Navigation bar at bottom:**
   - Three buttons evenly spaced:
     - **Dashboard** (left): navigates to `/` (dashboard)
     - **Try Again** (center): navigates to `/practice/{focusMode}` (same focus)
     - **New Session** (right): navigates to `/` (dashboard, where they pick a new focus)
   - Style: clear, tappable buttons. "Try Again" can be primary/accent styled.

5. **Edge case: no session data**
   - If sessionStorage has no data, redirect to dashboard
   - Guard against missing/corrupted data

**Styling:**
- Clean, centered layout consistent with clinical theme
- White card on light background
- Generous spacing
- Session duration formatted as Xm Ys (e.g., "1m 30s")

**SilenceNudge update:**

Update `src/components/SilenceNudge.tsx` to implement one-and-done behavior with coach tone.

New props interface:
```typescript
interface SilenceNudgeProps {
  /** Whether the silence threshold has been reached */
  triggered: boolean;
  /** Called when the nudge has been shown and dismissed (so parent can mark it as done) */
  onDismissed?: () => void;
}
```

Behavior changes:
1. **Coach tone message:** Replace "Still there? Start speaking to continue..." with something warm and encouraging:
   - "You've got this — start whenever you're ready"
   - Or pick from a small set of encouraging messages (Claude's discretion)
   - Tone: warm, motivating, not judgmental

2. **One-and-done behavior:**
   - When `triggered` becomes true, show the message with fade-in
   - After 4-5 seconds, auto-fade-out (regardless of whether user spoke)
   - After fade-out, call `onDismissed` to let parent know it's done
   - Parent (PracticeSession) should NOT re-trigger the nudge after it's been shown once

3. **Immediate dismiss on speech:**
   - If `triggered` becomes false while the nudge is visible (user started speaking), fade out immediately
   - Still call `onDismissed`

4. **Internal state management:**
   - Use `useState` for visibility and `useEffect` for auto-dismiss timer
   - The component manages its own show/hide lifecycle once triggered
