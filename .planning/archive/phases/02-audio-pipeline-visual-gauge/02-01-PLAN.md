Create a `SessionOrb` component — a neon green circle with icon inside and ambient glow.

**This is NOT the PlasmaOrb.** This is a fundamentally different design: a clean circle with an icon, ambient glow, and brightness reactivity. No plasma, no filaments, no canvas procedural rendering.

**Props interface:**
```typescript
interface SessionOrbProps {
  /** 0-1 audio level from mic — drives brightness during recording */
  audioLevel: number;
  /** Whether currently recording */
  isRecording: boolean;
  /** Pace state for color feedback: 'good' = green (default), 'fast' = yellow */
  paceState: 'good' | 'fast';
  /** Click handler */
  onClick: () => void;
  /** Whether the orb is in a loading/starting state */
  isLoading?: boolean;
  /** Whether click is disabled */
  disabled?: boolean;
  /** Optional size override in px (default 200) */
  size?: number;
}
```

**Implementation approach — CSS/HTML (NOT Canvas):**

The orb is a styled div, not a canvas. Use CSS for all visual effects:

1. **Base circle:** Rounded div with neon green background
   - Pick a vivid neon green (e.g., `#39FF14`, `#00FF41`, or similar — vivid, not muted)
   - `border-radius: 50%`
   - Fixed size (default 200px)

2. **Ambient glow:** CSS `box-shadow` with multiple layers
   - Concentric green glow effect: `box-shadow: 0 0 20px rgba(G, G, G, 0.4), 0 0 60px rgba(G, G, G, 0.2), 0 0 100px rgba(G, G, G, 0.1)`
   - Glow always present (idle and recording)

3. **Icon inside:** Centered SVG or icon element
   - **Idle/ready state:** Audio waveform bars icon (equalizer-style — 3-5 vertical bars of varying heights)
     - Can use an SVG with vertical rectangles at different heights
     - White or dark icon color for contrast against green
   - **Recording state:** Red stop square icon
     - Solid red (#EF4444 or similar) rounded-corner square
     - White or the red square itself centered in the circle
   - Smooth transition between icons (fade or swap)

4. **Volume-reactive brightness during recording:**
   - When `isRecording=true`, modulate the orb brightness based on `audioLevel` (0-1)
   - Use CSS `filter: brightness(...)` or adjust background color opacity/lightness
   - Whisper (audioLevel ~0-0.1): dimmer green, reduced glow
   - Normal speaking (0.1-0.5): vivid green, normal glow
   - Loud (0.5-1.0): brightest green, intensified glow (more box-shadow spread)
   - Apply via inline style: `style={{ filter: brightness(0.7 + audioLevel * 0.6) }}` (adjust range)
   - Glow intensity also scales with audioLevel (adjust box-shadow opacity/spread)

5. **Pace color feedback:**
   - When `paceState='good'`: green (default)
   - When `paceState='fast'`: yellow (e.g., `#FFD700` or `#FBBF24`)
   - Smooth CSS transition between colors: `transition: background-color 0.5s ease, box-shadow 0.5s ease`
   - Yellow glow replaces green glow when fast

6. **Idle state behavior:**
   - Completely static — NO animation, NO breathing, NO pulse
   - Just the circle + glow + waveform bars icon, sitting still
   - Cursor: pointer (clickable)
   - Hover: slight brightness increase (`filter: brightness(1.1)`)

7. **Loading state:**
   - Pulsing animation (CSS @keyframes) — opacity or scale pulse
   - Indicates "starting up"

8. **Disabled state:**
   - `cursor: not-allowed`, `opacity: 0.6`

**CSS file (SessionOrb.css):**
- `.session-orb-container` — base styles, cursor, transitions
- Hover states (non-disabled)
- Active (press) state — slight scale down
- Loading animation keyframes
- Disabled styles
- Focus-visible for keyboard accessibility
- `@media (prefers-reduced-motion)` — disable animations
- Mobile optimizations

**Accessibility:**
- `role="button"` and `tabIndex={0}` on the container
- `aria-label` describing state ("Start recording" / "Stop recording")
- `onKeyDown` handler for Enter/Space to trigger onClick

Create a `WaveformVisualizer` component that renders real-time audio amplitude as vertical bars, building left-to-right like an audio editor.

**Props interface:**
```typescript
interface WaveformVisualizerProps {
  /** AnalyserNode from Web Audio API — provides frequency/time domain data */
  analyserNode: AnalyserNode | null;
  /** Whether visualization is active (recording in progress) */
  isActive: boolean;
  /** Optional width in px (default: 100% of container) */
  width?: number;
  /** Optional height in px (default: 120) */
  height?: number;
}
```

**Implementation — HTML5 Canvas:**

1. **Canvas setup:**
   - Refs: `canvasRef`, `animationFrameRef`, `dataIndexRef` (tracks position for left-to-right build)
   - Set canvas dimensions with devicePixelRatio for crisp rendering
   - Light gray background (or transparent — sits on white page)

2. **Real-time amplitude rendering:**
   - When `isActive=true` and `analyserNode` exists:
     - Use `requestAnimationFrame` loop
     - Call `analyserNode.getByteTimeDomainData(dataArray)` each frame
     - Calculate RMS or peak amplitude from the current audio buffer
     - Draw a vertical bar at the current x-position
     - Advance x-position (dataIndexRef) for left-to-right build
     - When x reaches canvas width, either scroll/shift left or wrap to beginning

3. **Bar drawing:**
   - Each bar: narrow vertical rectangle (2-3px wide, 1px gap)
   - Height proportional to amplitude (centered vertically — bars grow up and down from center line)
   - Color: gray/dark (`#374151` or `#4B5563`) on light background
   - Draw a faint center line (1px, very light gray) as baseline

4. **Scroll behavior when canvas fills:**
   - Option A (preferred): Shift existing pixel data left by one bar width, draw new bar at right edge
     - Use `ctx.getImageData()` / `ctx.putImageData()` for shifting
   - Option B: Clear and redraw from stored amplitude history array
   - Either approach is fine — the visual effect should be continuous left-to-right scrolling

5. **Cleanup:**
   - Cancel animationFrame on unmount or when isActive becomes false
   - Clear canvas when session stops
   - Reset dataIndex when new session starts

6. **When not active:**
   - Show empty canvas with just the center baseline (or nothing)
   - Do not run animation loop

**Styling:**
- Rounded corners on canvas container (Tailwind: `rounded-lg`)
- Subtle border or background to define the waveform area
- Responsive: if no width prop, use 100% of parent container width
