Create the Practice Bridge page that shows a "What's next?" suggestion based on session performance.

**Suggestion Rules (IF/THEN):**
1. If practiced filler AND rate was high (>5/min) → suggest filler practice again with encouragement: "You're making progress! Try another filler practice session to lock in the improvement."
2. If practiced filler AND rate was low (≤2/min) → suggest pace practice or technique: "Great job on fillers! Ready to work on speech pace or try a new technique?"
3. If practiced pace → suggest filler or technique: "Nice work on pace! Try filler practice or explore a new technique."
4. If practiced technique → suggest different technique or free practice: "Well done! Try another technique or practice freely."

**Design:**
- Centered card layout (max-width: 600px)
- Title: "What's next?" (h2, Cormorant Garamond)
- Suggestion text: motivational, shows potential benefit
- Two buttons side-by-side:
  - Primary: "Try [suggestion]" (e.g., "Try Filler Practice", "Try Pace Practice")
  - Secondary: "Done for today" (always visible, prominent)
- Optional: small illustration or icon for visual interest

**Props:**
```ts
interface PracticeBridgeProps {
  lastSession: SessionResultData; // From sessionStorage or route state
}
```

**Navigation:**
- "Try [suggestion]" → navigates to appropriate practice route (`/practice/filler`, `/practice/pace`, `/library`)
- "Done for today" → navigates to `/` (dashboard)
- Back button → navigates to `/practice/results` (can review results again)

**Layout:**
- AppHeader with back button
- Centered content with card
- Suggestion text (body-lg, warm tone)
- Button row (flex, gap-4)
- Responsive: full width on mobile, centered card on desktop
