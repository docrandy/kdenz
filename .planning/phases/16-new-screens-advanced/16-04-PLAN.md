- Phase 1: Inhale (4 seconds)

- Phase 3: Exhale (4 seconds)
- Phase 4: Hold (4 seconds)

- `phase`: "inhale" | "hold1" | "exhale" | "hold2"
- `cycleCount`: number of completed cycles
- `isActive`: whether breathing is currently active
- `isPaused`: whether user paused (optional feature)

**Visual Design:**
- Full-screen, centered content
- Large animated circle (200-300px diameter) that expands/contracts
- Circle color: gold accent (`var(--color-gold-500)`) with opacity gradient
- Phase text below circle: "Breathe In", "Hold", "Breathe Out", "Hold"
- Cycle counter: "Cycle 1", "Cycle 2", etc.
- Control buttons: "Start", "Pause" (optional), "End"

**Animation (BreathingScreen.css):**
- `@keyframes breathe-in`: scale from 0.8 to 1.2 over 4s (ease-in-out)
- `@keyframes breathe-hold`: scale 1.2 (static) over 4s
- `@keyframes breathe-out`: scale from 1.2 to 0.8 over 4s (ease-in-out)
- `@keyframes breathe-hold2`: scale 0.8 (static) over 4s
- Circle uses `transform: scale()` for smooth expansion/contraction

**Layout:**
- AppHeader with back button (or hide for immersive experience)
- Centered vertically and horizontally
- Circle: ~250px diameter, gold with opacity 0.3-0.6
- Phase text: h3, Cormorant Garamond, below circle
- Cycle counter: body-sm, muted, below phase text
- Control button: "End" or "Done" at bottom

**Context Handling:**
- Read `location.search` for `?context=pre-session`
- If pre-session context: show "Skip" button instead of "End", navigate to recording after
- If standalone: show "End" button, navigate to dashboard after
