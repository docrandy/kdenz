  <files>src/components/StatCard.tsx</files>
  <action>
Create a reusable StatCard component for Voice Profile. This displays a metric with a trend indicator.

**Design:**
- Card layout: `card-surface` class (dark premium styling)
- Large value display (h2 size, accent color)
- Label text (body-sm, muted)
- Trend indicator: arrow icon (↑/↓/→) + percentage change + color coding
- Trend colors: green for improvement (filler down, WPM stable), amber for change, gray for stable

**Props:**
```ts
interface StatCardProps {
  label: string; // "Filler Rate", "Speech Pace", "Sessions", etc.
  value: number | string; // Current value
  unit?: string; // "per min", "WPM", etc.
  trend?: {
    direction: "up" | "down" | "stable";
    percentage: number; // e.g., -15.3 for 15.3% decrease
    period: string; // "vs last week", "vs first session"
  };
  empty?: boolean; // Show empty state placeholder
}
```

**Trend calculation:**
- Compare recent average (last 3-5 sessions) vs older average (sessions before that)
- For filler rate: down = improvement (green), up = worse (amber)
- For WPM: stable = good (green), large change = amber
- For session count: always informational (gray)

**Visual:**
- Arrow icon: ↑ (up), ↓ (down), → (stable)
- Percentage: "+15.3%" or "-15.3%" or "No change"
- Color: `text-status-success` (green), `text-status-warning` (amber), `text-text-muted` (gray)
  </action>

<task type="auto">
  <name>Task 2: Create BeforeAfterComparison component</name>
  <files>src/components/BeforeAfterComparison.tsx</files>
  <action>
Create the Before/After comparison component that shows side-by-side session metrics.

**Design:**
- Two cards side-by-side: "Session A" (left) vs "Session B" (right)
- Session selector dropdowns above cards (default: "Most Recent" vs "First Session")
- Metrics displayed: filler rate, WPM, duration, filler count (same as post-session scorecard)
- Delta indicators: percentage change, arrow direction, color coding
- Responsive: stack vertically on mobile

**Props:**
```ts
interface BeforeAfterComparisonProps {
  sessions: SessionSummary[]; // All sessions from sessionStorage
  defaultSessionA?: string; // Session ID for "before" (default: most recent)
  defaultSessionB?: string; // Session ID for "after" (default: first session or baseline)
}
```

**Session selection:**
- Dropdown shows: "Most Recent", "First Session", "Baseline" (if exists), then list of dates
- When user changes selection, update cards and recalculate deltas

**Delta calculation:**
- Filler rate: (B - A) / A * 100, show as percentage
- WPM: (B - A) / A * 100, show as percentage
- Duration: absolute difference in seconds, show as "+2:30" or "-1:15"
- Filler count: absolute difference, show as "+5" or "-3"

**Visual:**
- Cards use `card-surface` styling
- Delta badge below each metric: green for improvement, amber for worse, gray for neutral
- Arrow icon indicates direction
- "No baseline" message if no baseline exists and user selects baseline
  </action>
