  <name>Task 1: Create AnalysisLoader page with animated progress steps</name>
  <files>src/pages/AnalysisLoader.tsx, src/pages/AnalysisLoader.css</files>
  <action>
Create the Analysis Loader page. This is a full-screen loading experience shown after session recording stops.

**Design (per user decisions — LOCKED):**
- NOT the SessionOrb — custom animation that conveys "intelligence at work"
- Animated progress with step indicators
- Minimum 3 seconds display time
- Steps: "Analyzing your session..." → "Detecting patterns..." → "Generating insights..."

**Implementation:**

AnalysisLoader.tsx:
- Read session data from `sessionStorage` (same key as PostSessionResults: `voicelab_last_session`)
- If no session data, redirect to `/` (same guard as PostSessionResults)
- Show a centered animation with sequential step text
- Use `useState` to track which step is active (0, 1, 2, then "complete")
- Step timing: step 0 at 0ms, step 1 at 1200ms, step 2 at 2400ms, complete at 3600ms
- After reaching "complete" state, navigate to `/practice/results`
- Use `useNavigate` with `{ replace: true }` so back button doesn't return to loader

**Visual design:**
- Full screen, centered content, dark background (`bg-background`)
- Custom SVG animation: a set of concentric rings that pulse/rotate (conveys analysis/processing)
  - 3 concentric circles with different rotation speeds and gold accent color
  - CSS keyframes for rotation and opacity pulse
- Step text below the animation with fade-in transitions
- Each step has a small dot indicator that fills gold when active
- Current step text uses `text-text-heading`, past steps dim to `text-text-muted`
- Font: Cormorant Garamond for the step text (display font for premium feel)
- No progress bar — the step indicators ARE the progress indication

**AnalysisLoader.css:**
- `@keyframes orbit-ring-1`: slow rotation (20s full cycle)
- `@keyframes orbit-ring-2`: medium rotation (15s, reverse)
- `@keyframes orbit-ring-3`: fast rotation (10s)
- `@keyframes pulse-glow`: opacity 0.3 -> 1.0 -> 0.3 (2s cycle)
- `@keyframes fade-in-up`: translateY(8px) opacity 0 -> translateY(0) opacity 1 (400ms)
- Ring colors: `var(--color-gold-500)` with varying opacity (0.15, 0.25, 0.4)

**Layout:**
- `AppHeader` with `showBack` and `onBack={() => navigate('/')}` at top
- Centered vertically in remaining space
- Animation: ~120px diameter container for the rings
- Step list below with 20px gap
- Each step: dot (8px circle) + text, horizontal layout

Use `useEffect` with a series of `setTimeout` calls for step progression. Clean up timeouts on unmount.
