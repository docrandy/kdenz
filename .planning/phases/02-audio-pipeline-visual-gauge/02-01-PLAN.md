Create a `PlasmaOrb` component that renders a volumetric plasma sphere visualization.

**Props interface:**
```typescript
interface PlasmaOrbProps {
  /** 0-1 audio level from mic (drives brightness + filament speed) */
  audioLevel: number;
  /** 0-1 filler intensity (drives filament density / internal complexity) */
  fillerIntensity: number;
  /** Whether session is active (true = reactive mode, false = idle ambient) */
  isActive: boolean;
  /** Click handler (used for start/stop toggle) */
  onClick: () => void;
  /** Whether the orb is in a loading/starting state */
  isLoading?: boolean;
  /** Whether click is disabled */
  disabled?: boolean;
  /** Optional size override (default ~250px diameter) */
  size?: number;
}
```

**Visual implementation approach (Claude's discretion on exact technique):**

Option A (CSS + SVG): Multiple layered radial gradients with CSS animations. Inner filament lines using SVG filter turbulence. Glow effect using box-shadow and filter blur. This is simpler but may not achieve full volumetric feel.

Option B (Canvas 2D): HTML Canvas with procedural drawing. Concentric circles with varying opacity. Perlin noise or simplex noise for filament patterns. RequestAnimationFrame loop for smooth animation. Better volumetric feel, moderate complexity.

Option C (WebGL/Shader): Fragment shader for true volumetric rendering. Best visual quality but most complex. Only if achievable within task scope.

**Recommendation:** Start with Canvas 2D (Option B) for the best balance of visual quality and implementation speed. Fall back to CSS if Canvas proves too complex within task scope.

**Required visual states:**

1. **Idle state** (isActive=false): Gentle ambient animation. Slow filament drift. Dim glow. Subtle breathing effect (scale pulse ~2% over 3-4 seconds). Clear visual indication it's clickable (cursor: pointer, slight glow intensification on hover).

2. **Active speaking** (isActive=true, audioLevel > 0.1): Brighter overall glow. Faster filament movement proportional to audioLevel. More visible internal structure. Outer glow radius increases with audioLevel.

3. **Active silence** (isActive=true, audioLevel < 0.1): Dimmer than speaking but still "alive". Slow filament movement. Calmer than idle but clearly in "session active" state.

4. **High filler intensity** (fillerIntensity > 0.5): More filament lines visible. Denser internal patterns. Internal activity increases (not color change — stays teal/cyan). Think: "the orb gets busier inside."

5. **Loading state** (isLoading=true): Pulsing animation. Indicates "starting up" before mic is ready.

**Color palette (STRICT — no deviations):**
- Primary: #00D4FF (electric teal/cyan)
- Glow: rgba(0, 212, 255, 0.3) to rgba(0, 212, 255, 0.8)
- Filaments: lighter variations of #00D4FF (white-tinged cyan)
- Background shows through as white (#FFFFFF)
- NO other colors. Reactivity is ONLY through intensity/brightness/density.

**CSS file should contain:**
- @keyframes for any CSS-based animations (breathing, glow pulse)
- Hover states
- Transition properties for smooth state changes
- Media queries if needed for mobile sizing

**Performance requirements:**
- Animation at 60fps on Chrome desktop
- Graceful degradation on lower-end Chrome mobile (reduce particle count or animation complexity)
- No memory leaks from animation loops (clean up on unmount)
- Use requestAnimationFrame, not setInterval, for animation loops
