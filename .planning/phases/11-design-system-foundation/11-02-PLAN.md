**index.html:**

Add Google Fonts preconnect and stylesheet links in the `<head>` section, BEFORE the existing `<title>` tag:

```html
<!-- Google Fonts: Cormorant Garamond (headings) + Outfit (body) -->
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Cormorant+Garamond:ital,wght@0,400;0,500;0,600;0,700;1,400;1,500&family=Outfit:wght@300;400;500;600;700&display=swap" rel="stylesheet">
```

This matches the exact font import from the prototype HTML. Include weights:
- Cormorant Garamond: 400, 500, 600, 700 (normal + italic 400, 500)
- Outfit: 300, 400, 500, 600, 700

**tailwind.config.js:**

Update the `fontFamily` section under `theme.extend`:

```js
fontFamily: {
  heading: ['"Cormorant Garamond"', 'Georgia', 'serif'],
  body: ['Outfit', 'Inter', 'system-ui', 'sans-serif'],
  sans: ['Outfit', 'Inter', 'system-ui', 'sans-serif'],  // Override default sans
},
```

Add a `fontSize` section under `theme.extend` for the typographic scale (8px baseline grid):

```js
fontSize: {
  // Heading scale (desktop sizes, mobile handled via responsive)
  'display': ['3rem', { lineHeight: '1.1', letterSpacing: '0.02em' }],       // 48px - h1
  'h1': ['2.25rem', { lineHeight: '1.2', letterSpacing: '0.015em' }],        // 36px - h2
  'h2': ['1.75rem', { lineHeight: '1.2', letterSpacing: '0.01em' }],         // 28px - h3
  'h3': ['1.5rem', { lineHeight: '1.3', letterSpacing: '0.01em' }],          // 24px - h4
  'h4': ['1.25rem', { lineHeight: '1.3', letterSpacing: '0.005em' }],        // 20px - h5
  'h5': ['1.125rem', { lineHeight: '1.4', letterSpacing: '0' }],             // 18px - h6
  // Body scale
  'body-lg': ['1.125rem', { lineHeight: '1.6' }],   // 18px
  'body': ['1rem', { lineHeight: '1.6' }],           // 16px (default)
  'body-sm': ['0.875rem', { lineHeight: '1.5' }],    // 14px
  'caption': ['0.75rem', { lineHeight: '1.4' }],     // 12px
  'overline': ['0.6875rem', { lineHeight: '1.4', letterSpacing: '0.08em', fontWeight: '600' }],  // 11px
},
```

Note: The `letterSpacing` values on headings give the premium feel specified in TYP-06. Body text uses normal spacing.
