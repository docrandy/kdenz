Replace the content of src/index.css with the full design token system and updated base styles.

Structure:

1. **Tailwind directives** (keep existing):
```css

```

2. **CSS custom properties in `:root`** (add after directives, before @layer):
```css
:root {
  /* Background tokens */
  --bg-deep: #0b0e14;
  --bg-surface: #131720;
  --bg-elevated: #1a1f2e;
  --bg-hover: #222838;

  /* Text tokens */
  --text-primary: #e8e2d6;
  --text-secondary: #9a9484;
  --text-muted: #5e5a52;
  --text-inverse: #0b0e14;

  /* Accent tokens */
  --accent: #c9a84c;
  --accent-soft: rgba(201, 168, 76, 0.15);
  --accent-glow: rgba(201, 168, 76, 0.08);

  /* Status tokens */
  --positive: #6b9e78;
  --positive-soft: rgba(107, 158, 120, 0.15);
  --caution: #c9a84c;
  --caution-soft: rgba(201, 168, 76, 0.15);
  --stress: #b87171;
  --stress-soft: rgba(183, 113, 113, 0.15);

  /* Border tokens */
  --border-subtle: #1f2937;
  --border-accent: rgba(201, 168, 76, 0.2);

  /* Spacing base */
  --space-unit: 4px;
}
```

NOTE: Use `rgba()` instead of hex+alpha (e.g., `#c9a84c26`) for the soft/glow tokens to ensure broader browser compatibility and readability.

3. **Base layer** (update existing):
```css
@layer base {
  body {
    @apply bg-premium-deep text-premium-primary antialiased;
    font-family: 'Outfit', 'Inter', system-ui, -apple-system, sans-serif;
    line-height: 1.5;
    -webkit-font-smoothing: antialiased;
    -moz-osx-font-smoothing: grayscale;
  }

  /* Heading defaults (Cormorant Garamond applied in Plan 02) */
  h1, h2, h3, h4, h5, h6 {
    color: var(--text-primary);
    line-height: 1.2;
  }

  /* Link defaults */
  a {
    color: var(--accent);
  }

  /* Selection styling for dark theme */
  ::selection {
    background: var(--accent-soft);
    color: var(--text-primary);
  }
}
```

IMPORTANT: The body now applies `bg-premium-deep` and `text-premium-primary` which reference the CSS custom properties. This makes the entire app dark-themed at the base level. Existing components using hardcoded `bg-white text-black` etc. will still override this (Phase 12 handles migration).
