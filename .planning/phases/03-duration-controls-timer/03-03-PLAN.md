    **Update `src/core/audio/useSessionTimer.ts` — support Unlimited mode:**
    - When `durationSeconds` is 0 (Unlimited), the timer should:
      - Still track `elapsedTime` (counting up)
      - NEVER fire `onComplete` — timer runs indefinitely
      - `timeRemaining` returns Infinity or -1 to signal unlimited
      - `isComplete` stays false
    - Add a check: `if (durationSeconds === 0) { /* skip completion check */ }`
    - Keep all existing behavior for timed sessions (durationSeconds > 0)

    **Update `src/components/PracticeSession.tsx` — dynamic duration + countdown:**
    1. Import `useLocation` from react-router-dom
    2. Read duration from route state: `const location = useLocation(); const durationSeconds = (location.state as any)?.durationSeconds ?? 120;`
    3. Replace the hardcoded `const selectedDuration = 120;` with the dynamic value from route state
    4. Update SessionProgressBar usage:
       - Change from progress (0->1) to countdown remaining (1->0)
       - Calculate: `const countdownRemaining = durationSeconds > 0 ? Math.max(0, 1 - (elapsedTime / durationSeconds)) : undefined;`
       - Pass: `<SessionProgressBar remaining={countdownRemaining} visible={isCapturing && !isPaused && durationSeconds > 0} />`
       - For Unlimited mode (durationSeconds === 0): `visible` is false, so no bar shows
    5. The `useSessionTimer` hook already receives `durationSeconds` — now it comes from route state
    6. Keep ALL existing session logic (audio capture, filler detection, WPM calc, silence detection, pause/resume, stop/navigate)
