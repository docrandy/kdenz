<migration_reference>
## Color Migration Mapping (apply to ALL files in this plan)

### Background replacements
- `bg-white` → `bg-background` (page-level) or `bg-background-surface` (card/panel)
- `bg-gray-50`, `bg-gray-100` → `bg-background-surface` or `bg-background-elevated`
- `bg-gray-200`, `bg-gray-300` → `bg-background-elevated`
- `bg-clinical-bg` → `bg-background`
- `bg-clinical-accent` → `bg-accent`
- `bg-black` → `bg-background` (contextual — dark-on-dark becomes surface distinction)

### Text replacements
- `text-gray-900`, `text-clinical-text`, `text-black` → `text-text`
- `text-gray-700`, `text-gray-600` → `text-text-muted`
- `text-gray-500`, `text-gray-400`, `text-clinical-muted` → `text-text-subtle`
- `text-white` (on dark bg) → `text-text`; (on accent bg) → `text-text-inverse`
- `text-clinical-accent` → `text-accent`

### Border replacements
- `border-gray-200`, `border-gray-300`, `border-clinical-border` → `border-background-elevated`
- `border-gray-100` → `border-background-surface`

### Status color replacements
- `text-red-*`, `bg-red-*` → `text-status-error`, `bg-status-error/10` (or `/15` for badges)
- `text-green-*`, `bg-green-*` → `text-status-success`, `bg-status-success/10`
- `text-blue-*`, `bg-blue-*` → `text-status-info`, `bg-status-info/10`
- `text-yellow-*`, `text-amber-*`, `bg-yellow-*`, `bg-amber-*` → `text-status-warning`, `bg-status-warning/10`

### Accent replacements
- `#00D4FF` references → `text-accent` or `bg-accent`
- `clinical-accent` → `accent`
- `clinical-accent-hover` → `accent-hover`

### Interactive states
- `hover:bg-gray-50`, `hover:bg-gray-100` → `hover:bg-background-elevated`
- `hover:bg-gray-200` → `hover:bg-background-subtle`
- `hover:text-gray-900` → `hover:text-text`
- `focus:ring-blue-*`, `focus:ring-clinical-accent` → `focus:ring-accent`

### Shadow treatment on dark
- `shadow-sm`, `shadow-md`, `shadow-lg` → keep as-is (already remapped in design tokens)
- `shadow-none` → keep as-is
- If a component relies on shadow for depth on white bg, consider adding `border border-background-elevated` for depth on dark

### Gradient / ring replacements
- `from-*`, `to-*`, `via-*` with gray/blue/teal → use navy/gold scale equivalents
- `ring-*` with blue/gray → `ring-accent` or `ring-background-elevated`

### Per CONTEXT decisions
- Gold accent sparingly — primary CTAs only
- Secondary interactive: cream/white tones
- Hover effects: subtle brightening (hover:bg-background-elevated or hover:bg-background-subtle)
- Shadow on dark: keep existing shadows, add borders where shadows alone lose depth
</migration_reference>
