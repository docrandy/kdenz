  <name>Task 1: Upgrade typography scale tokens and brightness hierarchy</name>
  <files>tailwind.config.js, src/index.css</files>
  <action>
  **Typography scale upgrade (tailwind.config.js):**

  Increase ALL font sizes by 2-3 levels to achieve Calm/Headspace aesthetic — large, generous, unhurried. The current scale is too small per user feedback. New target sizes:

  ```
  Heading scale (Cormorant Garamond):
    display: 4rem (64px) [was 3rem/48px] — lineHeight 1.1, letterSpacing 0.02em
    h1: 3rem (48px) [was 2.25rem/36px] — lineHeight 1.15, letterSpacing 0.015em
    h2: 2.25rem (36px) [was 1.75rem/28px] — lineHeight 1.2, letterSpacing 0.01em
    h3: 1.75rem (28px) [was 1.5rem/24px] — lineHeight 1.25, letterSpacing 0.01em
    h4: 1.5rem (24px) [was 1.25rem/20px] — lineHeight 1.3, letterSpacing 0.005em
    h5: 1.25rem (20px) [was 1.125rem/18px] — lineHeight 1.4

  Body scale (Outfit):
    body-lg: 1.25rem (20px) [was 1.125rem/18px] — lineHeight 1.6
    body: 1.125rem (18px) [was 1rem/16px] — lineHeight 1.6
    body-sm: 1rem (16px) [was 0.875rem/14px] — lineHeight 1.5
    caption: 0.875rem (14px) [was 0.75rem/12px] — lineHeight 1.4
    overline: 0.75rem (12px) [was 0.6875rem/11px] — lineHeight 1.4, letterSpacing 0.08em, fontWeight 600
  ```

  **Brightness hierarchy (src/index.css):**

  Add two new CSS custom properties to :root for the brightness hierarchy:
  ```css
  --color-heading: #d4cbb8;   /* warm-white for headings */
  --color-body: #a09888;       /* muted brown for body text */
  ```

  Add corresponding Tailwind semantic tokens in tailwind.config.js under `text`:
  ```js
  heading: "var(--color-heading)",
  body: "var(--color-body)",
  ```

  **Update base heading styles (src/index.css):**

  Change the heading rule from `color: var(--color-cream-100)` to `color: var(--color-heading)` for the gentle warm-white.

  Update body base style to use `color: var(--color-body)` instead of the current `text-text` which maps to cream-100.

  Update the heading size assignments to match new scale:
  ```css
  h1 { @apply text-display font-semibold; }
  h2 { @apply text-h1 font-semibold; }
  h3 { @apply text-h2 font-medium; }
  h4 { @apply text-h3 font-medium; }
  h5 { @apply text-h4 font-medium; }
  h6 { @apply text-h5 font-medium; }
  ```
  (These stay the same — the sizes themselves have increased.)

  **Update component layer (src/index.css):**

  Update `.btn` base to use `text-body` size (now 18px).
  Update `.card-surface` and `.card-elevated` to use body color.
  Update `.text-style-overline` to match new overline size (0.75rem).

  **Important:** Keep the existing `text.DEFAULT` (cream-100) available as it may still be used. The new `text-heading` and `text-body` classes provide the brightness hierarchy on top of the existing system. Components will explicitly opt into heading vs body color.
  </action>

<task type="auto">
  <name>Task 2: Migrate all components and pages to semantic typography</name>
  <files>All component and page .tsx files (~48 files)</files>
  <action>
  Systematically replace hardcoded Tailwind text sizes with semantic scale tokens across ALL component and page files. This is a bulk migration. For each file:

  **Size mapping (old → new):**
  - `text-xs` → `text-caption` (14px, was 12px — generous increase)
  - `text-sm` → `text-body-sm` (16px, was 14px)
  - `text-base` → `text-body` (18px, was 16px)
  - `text-lg` → `text-body-lg` (20px, was 18px)
  - `text-xl` → `text-h5` (20px)
  - `text-2xl` → `text-h4` (24px)
  - `text-3xl` → `text-h3` (28px)
  - `text-4xl` → `text-h2` (36px)

  **Color hierarchy mapping:**
  - Section headings / card titles / primary labels: `text-text-heading` (warm-white)
  - Body text / descriptions / secondary content: `text-text-body` (muted)
  - Muted text / timestamps / helper text: keep `text-text-muted` or `text-text-subtle`
  - Key metric values (big numbers like filler count, WPM): `text-accent` (gold) — per user decision, use sparingly
  - Section overlines / category labels: `text-accent` with `text-style-overline` class

  **Specific component guidance:**

  **Dashboard.tsx:**
  - `VoiceLab` header: `text-h4 font-bold text-text-heading`
  - Section headings ("Practice", "Recent Sessions"): `text-h5 font-semibold text-text-heading`
  - Practice card titles: `text-body font-semibold text-text-heading`
  - Practice card descriptions: `text-body-sm text-text-body`
  - Session card text: `text-body text-text-heading` for primary, `text-body-sm text-text-body` for secondary
  - Stats numbers: `text-h3 font-bold text-accent`

  **PostSessionResults.tsx:**
  - "Session Complete" heading: `text-h1 font-bold text-text-heading`
  - Summary paragraph: `text-body-lg text-text-body`
  - "All Set!" heading: `text-h1 font-bold text-text-heading`

  **MetricCard.tsx:**
  - Card label (h4): `text-body-lg font-semibold text-text-heading`
  - Primary value: `text-h3 font-bold text-accent` (gold for key metrics)
  - Unit text: `text-body text-text-body`
  - Confidence interval: `text-body-sm text-text-muted`
  - Context notes: `text-caption text-text-muted italic`

  **Scorecard.tsx:**
  - Section heading: `text-h5 font-semibold text-text-heading`
  - Summary row: `text-body-sm text-text-muted`

  **AISummary.tsx:**
  - Section heading: use `text-h5 font-semibold text-text-heading`
  - AI response text: `text-body text-text-body`

  **PracticeSession.tsx:**
  - Prompt text: `text-h4 font-display text-text-heading` (Cormorant Garamond for breathing prompts — per user decision for "key elevated moments")
  - Timer display: `text-h3 font-bold text-text-heading`
  - Status text: `text-body text-text-body`

  **WelcomeScreen.tsx:**
  - Welcome heading: `text-h1 font-display font-bold text-text-heading`
  - Subtitle: `text-body-lg text-text-body`

  **SelfAssessment.tsx, ImplementationIntention.tsx:**
  - Question text: `text-h4 font-display text-text-heading` (Cormorant Garamond for insight callouts)
  - Instructions: `text-body text-text-body`

  **ScenarioLibrary.tsx, ScenarioDetail.tsx, TechniqueFeedback.tsx:**
  - Page titles: `text-h2 font-bold text-text-heading`
  - Section headers: `text-h4 font-semibold text-text-heading`
  - Body content: `text-body text-text-body`
  - Category labels: `text-style-overline text-accent`

  **All other components:** Apply the same pattern — headings get `text-text-heading`, body gets `text-text-body`, muted stays `text-text-muted` or `text-text-subtle`. Replace all hardcoded `text-xs/sm/base/lg/xl/2xl/3xl/4xl` with semantic tokens.

  **Also apply Cormorant Garamond (`font-display`) to these "key elevated moments":**
  - Session titles / "Session Complete" heading
  - Breathing prompts in PracticeSession
  - Insight callouts in SelfAssessment and ImplementationIntention
  - Welcome screen heading
  - Section overlines (already have `text-style-overline` which inherits from base)

  **Remove responsive size pairs:** Current code has patterns like `text-sm sm:text-base` — replace with single semantic token since the new scale is already generous. The semantic sizes are large enough that they work well at all breakpoints. Exception: if a component genuinely needs two different sizes for mobile vs desktop, use `text-body-sm sm:text-body` pattern.

  **WARNING: Do NOT change any component logic, state management, props, or behavior.** This is purely a typography/color class migration. Only Tailwind class strings should change.
