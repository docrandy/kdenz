    STATE MACHINE STATES:
    export type DrillState =
      | 'idle'        // no technique selected yet (should not show DrillScreen)
      | 'presenting'  // scenario is displayed, waiting for user to start recording
      | 'recording'   // Web Speech API active, user speaking
      | 'scoring'     // transcript received, evaluating (Gemini in flight)
      | 'feedback'    // scores available, feedback card shown
      | 'complete'    // no more scenarios in session pool (all used)

    HOOK INTERFACE (what DrillScreen receives from useDrillSession):

    export function useDrillSession(techniqueId: string) {
      // State
      state: DrillState
      technique: Technique | undefined
      currentScenario: Scenario | undefined
      transcript: string                  // live transcript during recording
      evaluation: DrillEvaluationResult | null
      attemptCount: number                // total attempts this session
      streak: number                      // consecutive correct streak
      sessionStartTime: string            // ISO 8601, set on first scenario load
      error: string | null                // transcription error message

      // Handlers
      startSession(): void                // load technique, pick first scenario, go to 'presenting'
      startRecording(): void              // transition to 'recording'
      appendTranscript(text: string): void  // called by DrillScreen as Web Speech API fires results
      submitTranscript(): Promise<void>   // transition to 'scoring', run evaluation, save attempt, go to 'feedback'
      nextScenario(): void                // pick next random scenario, go to 'presenting'
      setError(msg: string): void         // set error message, stay in 'presenting' for retry
      clearError(): void
    }

    IMPLEMENTATION DETAILS:

    1. Scenario pool management:
       - On startSession(): load all scenarios for techniqueId via getScenariosForTechnique()
       - Track usedScenarioIds: string[] in state (starts empty)
       - pickScenario(): pick random from scenarios not in usedScenarioIds
         - If all used: reset usedScenarioIds (allow repeats after full cycle)
       - On nextScenario(): pick next, add previous to usedScenarioIds, transition to 'presenting'

    2. Scoring in submitTranscript():
       - If transcript.trim() is empty: call setError("Inaudible response. Please speak clearly and try again.") and return
       - Transition state to 'scoring'
       - Get apiKey from getStoredApiKey() (imported from geminiService.ts)
       - Call evaluateDrillResponse(transcript, technique, currentScenario, apiKey)
       - On success: set evaluation, update streak logic, call saveDrillAttempt(), transition to 'feedback'
       - On unexpected throw: transition to 'presenting', setError("Could not process your response. Please try again.")

    3. Streak logic in submitTranscript():
       - After evaluation:
         const isCorrect = evaluation.formScore >= 80 && (evaluation.accuracyScore === null || evaluation.accuracyScore >= 75)
         if (isCorrect) setStreak(prev => prev + 1)
         else setStreak(0)
       - NOTE: if accuracyScore is null (Gemini failed), only use formScore for streak

    4. saveDrillAttempt call:
       saveDrillAttempt({
         id: generateAttemptId(),
         timestamp: new Date().toISOString(),
         techniqueId,
         scenarioId: currentScenario.id,
         transcript,
         formScore: evaluation.formScore,
         accuracyScore: evaluation.accuracyScore,
         impactScore: evaluation.impactScore,
         timingScore: 0,
         compositeScore: evaluation.compositeScore,
         explanation: evaluation.explanation,
         geminiSucceeded: evaluation.geminiSucceeded,
       })

    5. sessionStartTime:
       - Set to new Date().toISOString() on the first startSession() call
       - Persist in useState (not ref — component may re-render)

    6. Imports needed:
       - { useState, useCallback } from 'react'
       - { Technique, Scenario } from '../../types/drill'
       - { getTechnique, getScenariosForTechnique } from '../../utils/drill-storage'
       - { DrillEvaluationResult, evaluateDrillResponse } from '../../services/drillEvaluationService'
       - { saveDrillAttempt, generateAttemptId } from '../../utils/drillAttemptStorage'
       - { getStoredApiKey } from '../../services/geminiService'

    7. Return object from hook — flat (no nested objects), matches DrillScreen's needs exactly.

    CHROME-ONLY NOTE: The hook does NOT do Chrome detection — that is DrillScreen's job.
    The hook only manages state; it does not start the Web Speech API — that is DrillScreen's job.
    DrillScreen calls appendTranscript() as SpeechRecognition fires results.
    DrillScreen calls submitTranscript() when user taps Stop.
