  <action>
Rewrite SessionOrb.tsx and SessionOrb.css to create a premium animated orb. The component MUST keep the exact same exported interface (SessionOrbProps: audioLevel, isRecording, onClick, isLoading, disabled, size).

**Architecture: Use SVG for the rings, div for the body.**

The component structure should be a wrapper div containing:
1. An SVG element (position: absolute, full size + ring spread) with 3 concentric circle/ring elements
2. A central div (the orb body) with gold radial gradient
3. Icon overlay (mic waveform or stop square) centered on the body

**Orb Body (ORB-01):**
- Replace flat `backgroundColor: "#c9a84c"` with a CSS radial gradient
- Gradient: center highlight lighter gold (#d4b35a or brighter) fading to standard gold (#c9a84c) at edges, with a subtle darker rim (#b8963f) at the very edge
- This gives the appearance of a lit sphere with depth
- Keep the border-radius: 50% for the circular shape
- Keep the box-shadow glow but make it more refined — gold ambient glow at rest

**Three Concentric Animated Rings (ORB-02):**
- Render as SVG `<circle>` elements with `stroke` (no fill), positioned around the orb body
- Use `stroke-dasharray` and `stroke-dashoffset` for segmented/dashed ring appearance
- Each ring is a separate SVG circle at a different radius

Ring specifications (Claude's discretion on exact values, these are starting points):

Outer ring (slow rotation):
- Radius: orbSize/2 + 28px gap from body edge
- Stroke width: 1.5px
- Color: rgba(201, 168, 76, 0.2) at rest
- Animation: CSS `@keyframes orb-ring-rotate` — continuous 360deg rotation at 20s duration, linear
- Dash pattern: long dashes with medium gaps (e.g., stroke-dasharray: 40 20)

Middle ring (medium pulse):
- Radius: orbSize/2 + 18px gap from body edge
- Stroke width: 2px
- Color: rgba(201, 168, 76, 0.3) at rest
- Animation: CSS `@keyframes orb-ring-breathe` — scale oscillation between 0.97 and 1.03 at 3s duration, ease-in-out
- Dash pattern: medium dashes (e.g., stroke-dasharray: 15 10)

Inner ring (fast flicker/shimmer):
- Radius: orbSize/2 + 8px gap from body edge
- Stroke width: 1px
- Color: rgba(201, 168, 76, 0.25) at rest
- Animation: CSS `@keyframes orb-ring-shimmer` — opacity oscillation between 0.15 and 0.5 at 1.5s duration, with slight rotation at 12s
- Dash pattern: short dashes (e.g., stroke-dasharray: 8 6)

The SVG should use `viewBox` calculated from the total size (body + ring spread). Set the SVG to position: absolute, centered over the orb body with overflow visible.

**Volume Responsiveness (ORB-03):**
- When `isRecording` is true, use `audioLevel` (0-1) to modulate ring properties via inline styles:
  - Ring stroke opacity: base opacity + (audioLevel * opacity boost). E.g., outer goes from 0.2 to 0.5, middle from 0.3 to 0.7, inner from 0.25 to 0.6
  - Ring stroke width: slight increase with volume. E.g., outer 1.5 → 2px, middle 2 → 2.5px, inner 1 → 1.5px
  - Orb body glow (box-shadow): increase spread and opacity with audioLevel (similar to current but more dramatic)
  - Apply a subtle scale to the orb body: 1.0 + audioLevel * 0.03 (just enough to feel alive, not distracting)
- When NOT recording (idle), rings use their base/rest values
- Use CSS transition on stroke properties for smooth interpolation (transition: stroke-opacity 0.15s ease, stroke-width 0.15s ease)
- Sensitivity curve: use `Math.pow(audioLevel, 0.7)` to make it more responsive at low volumes and compress at high volumes

**Icons (ORB-04, ORB-05):**
- Keep the existing WaveformBarsIcon (mic waveform bars) for idle state — shows centered in orb
- Keep the existing StopSquareIcon for recording state — shows centered in orb
- Change the icon fill from `#0b0e14` to `var(--color-navy-950)` for the waveform (dark on gold)
- Change the stop square fill from `#e8e2d6` to `var(--color-cream-100)` (cream on gold)
- Icons should scale proportionally if `size` prop changes. Use percentage-based SVG sizing or calculate from size prop.
- Add a smooth crossfade transition between icons: when switching from waveform to stop (or vice versa), fade out old icon (opacity 0) then fade in new icon (opacity 1) over ~200ms

**State Transitions (ORB-06):**
- Idle state: rings animate at their rest speeds/opacities, body at rest brightness, waveform icon visible
- Recording state: rings brighten per volume, body glow intensifies, stop icon visible
- Loading state (isLoading): gentle pulse animation on the entire orb (scale 1 → 0.95 → 1), rings animate at reduced opacity (dimmed). Keep cursor: wait.
- Disabled state: reduce opacity to 0.5, desaturate, stop ring animations. Keep cursor: not-allowed.
- Transition between states: use CSS transitions on the wrapper with ~300-500ms ease for smooth morphing
- The transition from idle → recording should feel like the orb "waking up" — rings brighten, glow intensifies
- The transition from recording → idle should feel like the orb "settling down" — rings dim back to rest

**Responsive Sizing (ORB-07):**
- The `size` prop controls the orb body diameter (default 200px)
- Ring radii, gaps, and stroke widths should scale proportionally with size
- The total footprint (body + rings) is approximately size + 70px (for the ring spread)
- At 320px viewport: ensure the orb + rings don't overflow. The consuming component (PracticeSession) handles centering. Set max-width on the wrapper if needed.
- SVG viewBox should be calculated dynamically from size + ring spread
- Touch target: the clickable area should be at least 48x48px (already handled by the body being 200px default)
- At small screens, the orb body minimum should be respected (the parent doesn't pass sizes below ~120px, but ensure it works)

**CSS Keyframes (in SessionOrb.css):**
Define all ring animation keyframes in SessionOrb.css (NOT tailwind.config.js) since these are component-specific:

```css
@keyframes orb-ring-rotate {
  from { transform: rotate(0deg); }
  to { transform: rotate(360deg); }
}

@keyframes orb-ring-breathe {
  0%, 100% { transform: scale(1); }
  50% { transform: scale(1.03); }
}

@keyframes orb-ring-shimmer {
  0%, 100% { opacity: 0.15; transform: rotate(0deg); }
  50% { opacity: 0.5; transform: rotate(15deg); }
}
```

**Reduced Motion (important):**
- Inside `@media (prefers-reduced-motion: reduce)`, disable ALL ring animations (animation: none)
- Keep the static visual (gradient, rings visible at rest opacity, icons) but no movement
- This is required for accessibility

**DO NOT:**
- Change the exported component name or prop interface
- Add new props or remove existing props
- Import any new external libraries (pure CSS + SVG)
- Modify PracticeSession.tsx — the contract must stay identical
- Use canvas or WebGL — CSS animations and SVG only
- Add keyframes to tailwind.config.js (keep them in SessionOrb.css)
