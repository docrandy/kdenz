<objective>
Build the session debrief — the culmination of the biofeedback mirror. After a
conversational drill session ends, the user sees a 5-card sequential stack that makes
invisible patterns visible:

1. RevealCard — "What was actually there" (the holy shit moment, receiving channel)
2. SendingFeedbackCard — "What you signaled" (pattern name + behavioral observations)
3. GrowthEdgeCard — One specific behavior to try next session
4. NextStepCard — 1 Institute item surfaced with personalization ("why this for you")
5. ProgressSignalCard — Trajectory toward/away from aspiration target

This is NOT a scorecard. It's a mirror: "Here's who you are as a communicator right now.
Here's the gap between that and who you want to be. Here's your next step."

Purpose: Session debrief = pattern name + growth edge + one next step (locked decision).
The debrief is where biofeedback becomes self-identification becomes targeted action.

Output: debriefService (Gemini Call 3), DebriefCardStack UI, wired into ConversationalDrill
session end flow.
</objective>

    Create the debrief service that calls Gemini at session end to synthesize all

    SESSION DEBRIEF TYPE:
    ```typescript
    export interface SessionDebrief {
      // RevealCard data
      characterSubtext: string;         // 1 sentence: what character was really feeling
      missedSignal: string;             // 1 sentence: what user responded to vs actual signal

      // SendingFeedbackCard data
      behavioralObservations: string[]; // 2-3 turn-referenced observations
      patternName: string;              // e.g., "Hedger" — only set if confidence >= 0.75
      patternFraming: string;           // "you tend to X when Y" sentence
      patternConfidence: number;        // 0-1

      // GrowthEdgeCard data
      growthEdge: string;               // single behavior, one session
      growthEdgeContext: string;         // aspiration connection

      // NextStepCard data
      nextStepType: 'drill' | 'institute';
      nextStepId: string;
      nextStepTitle: string;
      nextStepPersonalization: string;  // "why this for you"

      // ProgressSignalCard data
      trajectoryDirection: 'toward_target' | 'holding' | 'away_from_target';
      trajectoryNote: string;
      sessionNumber: number;
    }
    ```

    FUNCTION: generateSessionDebrief
    ```typescript
    export async function generateSessionDebrief(
      sessionHistory: Array<{ role: 'user' | 'character'; text: string }>,
      patternNotes: string[],             // from Call 2 per-exchange
      sessionPatternData: SessionPatternData,
      subtextLayer: SubtextLayer,         // from scenario
      aspirationProfile: UserAspiration | null,
      topInstituteItems: ScoredContent[], // from contentRoutingService
      patternHistory: PatternType[],      // last 10 sessions
      apiKey: string | null,
    ): Promise<SessionDebrief>
    ```

    IMPLEMENTATION:
    1. If no API key, return a FALLBACK debrief assembled from available data:
       - characterSubtext from subtextLayer.underlyingFear
       - behavioralObservations from sessionPatternData.regexSignals
       - patternName from sessionPatternData.sessionPattern
       - nextStep from topInstituteItems[0]
       - trajectoryDirection: 'holding' (can't compute without Gemini)

    2. If API key available, call Gemini with this prompt structure:
       - System: "You are a communication coach synthesizing a practice session debrief.
         Your tone is warm, observational, and growth-oriented. NEVER say 'you are a [pattern]'.
         Always say 'you tend to [behavior] when [context]'. Pattern name appears AFTER
         behavioral observation. Growth edge uses 'in your next session, try...' framing."
       - Include: full session history (truncated to last 10 exchanges if longer)
       - Include: all patternNotes from Call 2
       - Include: subtextLayer (what was really going on)
       - Include: aspiration profile (archetype name + markers)
       - Include: pattern history (last 10 sessions, for trajectory)
       - Include: top 5 Institute candidates (titles + IDs, for nextStep selection)
       - Temperature: 0.4 (coaching text should feel human, not robotic)
       - maxOutputTokens: 500
       - Output format: JSON matching SessionDebrief interface

    3. Parse Gemini response (same JSON extraction as drillEvaluationService):
       - Handle ```json code blocks
       - Validate required fields
       - Clamp confidence to 0-1
       - Map nextStepId to actual Institute content

    4. TRAJECTORY COMPUTATION:
       - If patternHistory.length < 2: trajectoryDirection = 'holding', note = "Building your baseline..."
       - If most recent 3 sessions show same pattern with decreasing confidence: 'toward_target'
       - If most recent 3 sessions show same pattern with same confidence: 'holding'
       - If most recent 3 sessions show new/worsening pattern: 'away_from_target'
       - Gemini can override this with its own trajectory assessment

    5. After debrief generated, call addPatternToHistory() to persist the session pattern.

    GRACEFUL DEGRADATION:
    - Gemini failure -> fallback debrief from local data (never empty)
    - No aspiration set -> omit aspiration-related fields, note "Set your target voice in Profile"
    - No pattern detected (< 3 exchanges) -> patternName = '', patternFraming = "Too few exchanges to identify a pattern"
    - No Institute items match -> nextStepType = 'drill', nextStepId = first prescribed drill from COMMUNICATOR_PATTERNS
