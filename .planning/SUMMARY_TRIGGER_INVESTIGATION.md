# Summary Trigger Issue Investigation

## User Report
**"It's not the summary at the end. It's giving me a summary after every message that I send."**

This indicates that coaching summaries or feedback are appearing **after each individual message** in a conversational session, rather than only at the end when the session completes.

---

## Code Investigation Results

### ConversationalDrill.tsx (Level 2+ Chat Practice)
**Status**: Does NOT generate per-message summaries ✓

The conversational drill flow:
1. User submits a label/message (line 414-579 `submitLabel`)
2. Label is analyzed with `analyzeLabel()` (line 424)
3. User message added to chat (line 534-541)
4. Character response generated via `generateCharacterResponse()` (line 553-575)
5. Character message added (line 561-566)
6. **Per-message flow ends** — no summary generation
7. After 10 exchanges (MAX_EXCHANGES), `handleSessionEnd()` is called (line 570-574)
8. `generateSessionDebrief()` creates a 5-card debrief (line 617-630)
9. `DebriefCardStack` shows cards one at a time (line 659-671)

**Conclusion**: ConversationalDrill correctly generates debrief ONLY at session end, not per-message.

---

### PostSessionResults.tsx (Voice Practice Debrief)
**Status**: Generates coaching summary when "Coaching" tab is first viewed ✓

Auto-trigger logic (lines 110-120):
```typescript
useEffect(() => {
  if (
    phase === "results" &&
    activeTab === "coaching" &&
    aiSummaryState === "idle" &&
    sessionData &&
    !sessionData.is_baseline
  ) {
    generateAISummary();  // ← Only when tab is FIRST viewed
  }
}, [phase, activeTab, aiSummaryState, sessionData]);
```

**Conclusion**: This is end-of-session only, not per-message.

### TechniqueFeedback.tsx (Technique Practice Debrief)

The `AISummary` component (line 321-329) is rendered on the "Coaching" tab of the technique feedback page, which appears AFTER the practice session completes.

## What Could Cause Per-Message Summaries?

Possible explanations:

### 1. **Panel B Content in ConversationalDrill**
   - Panel B shows "What you signaled" after each exchange (lines 80-152)
   - Displays pattern signals that update per-message
   - **Could user be calling this a "summary"?** Unlikely — it's labeled as "What you signaled" and shows pattern observations, not coaching summaries

### 2. **Character Reaction Feedback**
   - After each user message, the character responds based on label quality
   - Character response is generated by `generateCharacterResponse()` (line 553)
   - **This is not a "summary"** but might appear summary-like?

### 3. **LabelFeedback Component**
   - `LabelFeedback.tsx` exists but is NOT used in ConversationalDrill
   - This component shows affect-based feedback after a label attempt
   - Appears to be **dead code** or used in a different drill type

### 4. **Debrief Card Stack Appearing During Session**
   - `DebriefCardStack` is only shown after `showDebrief` is true (line 657)
   - `showDebrief` only set to true at end of session (line 634)
   - Unlikely this is triggering per-message

### 5. **AISummary Component in Conversation**
   - `AISummary` component is NOT imported or used in ConversationalDrill
   - Only used in PostSessionResults and TechniqueFeedback (end-of-session pages)
   - **Should not be appearing during conversation**

## Hypothesis

The user may be experiencing one of these:

1. **Panel B being interpreted as "summary"** — The "What you signaled" panel updates with pattern observations after each message, which could feel like a coaching summary
2. **Character reaction being interpreted as "summary"** — The character's response based on label quality analysis
3. **Debrief cards appearing prematurely** — If there's a bug causing `showDebrief` to trigger too early
4. **Modal/overlay feedback** — If `LabelFeedback` component is being shown modal-style after each attempt
