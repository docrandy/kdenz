## Hard Dependencies (MUST Master First)

| Advanced Technique | Hard Prerequisite(s) | Why |
|---|---|---|
| Mirroring | Active Listening | Can't reflect last words if not tracking content |
| Labeling | Emotional Self-Awareness | Can't name others' emotions if you can't identify your own |
| Tactical Empathy | Emotional Regulation + Active Listening | Empathy requires managing your own state while tracking theirs |
| Accusation Audit | Labeling + Perspective-Taking | It's pre-emptive labeling; must label competently first |
| Calibrated Questions | Open-Ended Questions + Tactical Empathy | Must know how to ask open questions before making them strategic |
| "That's Right" | Labeling + Summarizing | Requires accurate reflection → confirmation cycle |
| Black Swan Discovery | Calibrated Questions + Tactical Empathy + Perspective-Taking | Requires all listening/empathy tools working together |
| Ackerman Model | Anchoring + Emotional Regulation + Loss Aversion Framing | Must handle pressure and frame strategically |
| NVC Request | NVC Observation + Feeling + Need | Sequential framework — can't skip to request without the 3 priors |
| STATE Method | "I" Statements + Contrasting + Emotional Regulation | Integrates multiple foundational tools under stress |
| Rolling with Resistance | Reflective Listening + Affirmations + Emotional Regulation | MI advanced skill — requires all OARS + self-management |

### Soft Recommendations (helpful but not required)

- Vocal tonality control → Late-night FM DJ voice
- Active listening → All advanced techniques (general foundation)
- Emotional regulation → Everything involving empathy or conflict (universal support)

## Educational Platform Patterns

### Pattern 1: Atomic Units → Compound Skills (Khan Academy, Duolingo)

- Each skill = smallest testable behavior
- Skills unlock in directed acyclic graph (DAG), not strict linear
- Visual progress map shows mastery levels per node
- Mixed-skill assessments test retention + unlock next tier

### Pattern 2: Mastery Gating with Spaced Repetition (ScootPad, adaptive platforms)

- Mastery thresholds: 0.95 or 0.98 probability of correctness
- Spaced automatic checks (not just "pass once and move on")
- Higher mastery in Skill A → better performance in dependent Skill B
- **Recommendation: Use 0.95 for unlock, 0.98 for "Mastered" badge**

### Pattern 3: Skill Clusters with Flexible Unlock (Codecademy, language learning)

- Group related skills into modules (e.g., "Reflective Listening" module)
- Unlock next module when 70-80% of current module at "Proficient"
- Allow user to attempt any unlocked skill (choice within tier)

### For Communication Specifically

- Sequence: Interpersonal foundation → Verbal techniques → Written/Presentation → Advanced integration
- Emphasize practice in context (isolated drill → low-stakes roleplay → high-stakes simulation)

## Fundamentals Track (Mandatory)

**Research confirms: mandate a fundamentals track.** Mastery learning works when prerequisites are enforced.

### Tier 0 + Tier 1 (Complete Before Branching)

1. Emotional Self-Awareness (recognize your own emotional state in real time)
2. Emotional Regulation (manage arousal, avoid reactivity)
3. Active Listening (track content, avoid interrupting, show attention)
4. Vocal Tonality Control (modulate pace, pitch, volume deliberately)
5. Open-Ended Questions (ask "what/how" instead of yes/no)
6. "I" Statements (express impact without blame)
7. Assertiveness without Aggression (state needs while preserving respect)
8. Turn-Taking / Basic Conversational Flow (manage speaking turns)

**Unlock criteria:** 80% of fundamentals at Proficient

### Specialization Tracks (After Fundamentals)

- **Negotiation Track** (Voss + Camp techniques)
- **Difficult Conversations Track** (Crucial Conversations + Difficult Conversations + NVC)
- **Motivational Interviewing Track** (MI for coaching/healthcare/leadership)
- **Leadership Communication Track** (STATE + Feedback + Stakeholder framing)

## 5-Level Mastery System (Recommended Over 3-Level)

| Level | Name | What It Means | Visual |
|---|---|---|---|
| 0 | **Not Started** | Locked or never attempted | Gray / locked icon |
| 1 | **Attempted** | User tried, scored <70% correct in drill or failed in roleplay | Red / orange |
| 2 | **Familiar** | Scored 70-99% in isolated drill OR used correctly 1-2 times in roleplay | Yellow |
| 3 | **Proficient** | Scored 100% in isolated drill OR used correctly 3+ times across multiple roleplays | Green |
| 4 | **Mastered** | Maintained Proficient + demonstrated in mixed-skill assessment (retention check 7-14 days later) | Blue / gold star |

### Why 5 Levels

- Distinguishes "tried once" from "can do reliably"
- Mastered = retention confirmed (not just one-time success)
- Allows users to see incremental progress (motivation)

## Mastery Progression Criteria

### Attempted → Familiar
- Isolated drill: Improve from <70% to ≥70% correct responses
- Roleplay: Use technique at least once successfully (evaluator or AI confirms)

### Familiar → Proficient
- Isolated drill: Score 100% (all responses correct, no hints used)
- Roleplay: Use technique correctly in 3+ distinct conversational moments across 2+ scenarios

### Proficient → Mastered
- **Spaced retention check** (7-14 days after reaching Proficient): Still score ≥90% in isolated drill
- **Mixed-skill assessment**: Correctly apply this technique + 2-3 other techniques in a single integrated roleplay without prompting

### Tier Unlock Logic

| Gate Type | Rule |
|-----------|------|
| Hard prerequisite | MUST reach Proficient in prerequisite before attempting dependent skill |
| Tier progression (soft) | ≥75% of current tier at Proficient or higher to unlock next tier |
| Expert tier (Tier 3→4) | ≥80% of Tier 3 at Proficient (higher bar) |
| Mastery badge | Proficient + retention confirmed |

### Readiness Metrics

1. **Accuracy** — % correct in drills
2. **Consistency** — technique used appropriately across multiple scenarios
3. **Retention** — performance maintained after 7-14 day gap
4. **Transfer** — technique applied in novel/unseen scenarios
5. **Integration** — can combine with other techniques in complex conversations

## Concrete Skill Tree: Full Tier Breakdown

### Tier 0: Foundations (Complete All Before Tier 1)

**Unlock criteria:** New user onboarding complete

| Skill | Difficulty | Mastery Goal | Unlock Threshold |
|---|---|---|---|
| Emotional Self-Awareness | Foundational | Accurately name own emotions in 5+ practice moments | Proficient (100% accuracy in emotion ID drill) |
| Emotional Regulation | Foundational | Demonstrate grounding technique when triggered in 3+ simulations | Proficient (maintain composure in 3 escalation scenarios) |
| Active Listening | Foundational | Track content across 2-minute monologue, summarize accurately | Proficient (90%+ summary accuracy) |

**Gate:** All 3 → Proficient before Tier 1 appears.

### Tier 1: Core Techniques

**Unlock criteria:** Tier 0 complete (all Proficient)

| Skill | Difficulty | Prerequisites | Mastery Goal |
|---|---|---|---|
| Vocal Tonality Control | Foundational | None | Modulate pitch/pace deliberately in 5 practice clips |
| Open-Ended Questions | Foundational | None | Ask 10 open questions without yes/no slip |
| "I" Statements | Foundational | None | Deliver 5 "I feel X when Y" statements with no blame language |
| Minimal Encouragers | Foundational | Active Listening | Use "mm-hmm," nods, "go on" appropriately 10+ times |
| Assertiveness Basics | Foundational | "I" Statements | State boundary clearly in 3 scenarios without aggression |
| De-escalation Basics | Foundational | Emotional Regulation | Lower conversational intensity in 3 heated simulations |

**Gate:** ≥75% Proficient → unlock Tier 2A

**Unlock criteria:** Tier 2A ≥75% Proficient

## Implementation Notes

1. **Visual skill tree UI:** Node-and-edge graph (like Khan Academy) with color-coded mastery levels
2. **Postgres schema:** `user_skills` table with `skill_id`, `user_id`, `mastery_level` (0-4), `last_practiced`, `unlock_date`
3. **Unlock logic:** Edge function checks prerequisites on-demand before allowing drill/roleplay start
4. **Adaptive difficulty within skill:** Start at user's current mastery level, adjust rigor based on VCM constraint diagnosis
5. **Retention checks:** Automated reminders 7 days after reaching Proficient → "Quick check to lock in mastery"

## KDENZ Platform Implications

1. **Tier 0 replaces current onboarding.** Current 4-question diagnostic is too shallow. Tier 0 (Emotional Self-Awareness + Regulation + Active Listening) becomes the mandatory onboarding assessment — not a quiz, but drills that establish baseline.

2. **5-level mastery system replaces binary completion.** Current labeling/audit modules have no mastery tracking. Need `user_skills` table with 0-4 levels + last_practiced + unlock_date.

3. **Hard prerequisites are enforceable.** The DAG maps directly to a Supabase edge function: check `user_skills` for prerequisites before allowing drill start. Simple query.

4. **Specialization tracks map to user goals.** The 4 tracks (Negotiation, Difficult Conversations, MI, Leadership) align with the Profile page's "Long-term Goals" decision tree. Goal selection → recommended track.

5. **Retention checks = re-engagement mechanism.** 7-day automated "Quick check to lock in mastery" is both pedagogically sound and a retention/engagement feature. Push notification material.

6. **R8 platform-fit analysis needs updating.** R8 had 22 techniques for beta. R9 adds Tier 0 skills (Emotional Self-Awareness, Emotional Regulation, Active Listening) + Tier 1 additions (Minimal Encouragers, Turn-Taking, Assertiveness Basics) that weren't in R8. Total beta scope is now ~28-30 skills across 5 tiers (0-3 + partial Tier 4).

7. **NVC is a sequential hard lock.** Observation → Feeling → Need → Request must be learned in order. This is unique in the tree — most other techniques have soft dependencies. NVC needs special UI treatment (linear progression within the cluster).

8. **Generic drill engine confirmed as correct approach.** Same drill infrastructure serves all tiers. Only the evaluation rubric and mastery thresholds change per technique.
