## Technique Classification: Drill vs. Simulation vs. Both

### Tier A: Drills-First (Isolated Practice is PRIMARY)

Discrete, recognizable syntax that can be practiced in isolation before integration.

| Technique | Why Drillable | Skills Lab Format | Move to Simulation When |
|---|---|---|---|
| Mirroring | Single-turn, formulaic (repeat last 2-4 words + upward inflection) | Prompt → Mirror response → Syntax check | After 10 correct mirrors |
| Labeling | Single-turn, formula-based ("It sounds/seems/feels like...") | Emotional scenario → Label response → Emotion accuracy + syntax | After 15 accurate labels |
| Open-Ended Questions | Single-turn, syntax-driven (how/what, no yes/no) | Statement → Open question → Syntax validation | After 20 questions without yes/no slip |
| "I" Statements | Single-turn, structure-based ("I feel X when Y because Z") | Conflict prompt → "I" statement → Blame detection | After 10 blame-free statements |
| Vocal Tonality Control | Isolated audio drill (pitch, pace, volume modulation) | Read script → Record → Prosody analysis (Hume.ai) | After 10 clips with target tonality |
| Late-Night FM DJ Voice | Isolated audio drill (slow, calm, downward inflection) | Read de-escalation script → Tone analysis | After 5 clips meeting criteria |
| "No"-Oriented Questions | Single-turn, syntax-based (frame for comfortable "no") | Scenario → Rephrase as no-question → Syntax check | After 15 correct no-frames |
| NVC Observation | Single-turn (describe behavior without judgment) | Scenario → Observation statement → Judgment detection | After 10 judgment-free observations |
| NVC Feeling | Single-turn (name emotion, not evaluation) | Scenario → Feeling statement → Evaluation detection | After 10 pure feeling statements |
| Contrasting | Single-turn structure ("I don't mean X, I do mean Y") | Misunderstanding → Contrasting response → Structure check | After 10 correct contrasts |

**Design principle:** Isolate the syntax/structure until automaticity (can produce correctly without conscious effort).

### Tier B: Simulation-Preferred (Require Multi-Turn Context)

Depend on conversational flow, timing, or opponent response — can't be meaningfully practiced in isolation.

| Technique | Why Simulation-Only | Recognition Drill Possible? | Min Turns |
|---|---|---|---|
| "That's Right" | Requires iterative labeling/summarizing until spontaneous confirmation | Yes: "Which summary would trigger 'that's right'?" (multiple choice) | 3-5 |
| Black Swan Discovery | Requires exploratory questioning over many turns to uncover hidden info | Yes: "Identify the hidden constraint in this transcript" | 8-15 |
| Ackerman Model | Sequential negotiation with 5-step price progression | No: Too complex for drill | 10-20 |
| Bending Reality / Loss Aversion | Requires establishing rapport, then reframing stakes over multiple exchanges | Yes: "Rewrite this gain-frame as loss-frame" | 5-10 |
| Strategic Silence | Timing-dependent (pause after key statement, read opponent reaction) | Partial: Audio drill with pause timing, but needs live reaction | 2-4 |
| Rolling with Resistance (MI) | Requires recognizing sustain talk, reflecting without arguing, shifting naturally | Yes: "Identify sustain talk, write reflection" | 4-8 |
| Change Talk Elicitation (MI) | Requires building through OARS sequence until person voices desire/ability/reasons | Yes: "Which question elicits change talk?" | 3-6 |
| STATE Method | 5-step sequence must flow naturally | Partial: Can drill each step, but integration requires simulation | 5-10 |
| Three Conversations Model | Requires navigating "what happened," "feelings," "identity" dynamically | No: Too emergent | 15-30 |
| Jim Camp "Start with No" | Entire negotiation architecture | Partial: Can drill "permission to say no" opening | 10-20 |

**Design principle:** Build through guided simulations with scaffolding (e.g., "Try to discover at least one hidden constraint").

### Tier C: Both Environments (Drill Basics → Simulate Integration)

| Technique | Skills Lab Version | Simulation Version | Progression |
|---|---|---|---|
| Calibrated Questions | Turn demand into how/what question | Use strategically to shift problem-solving to opponent | Drill until syntax automatic → Simulate timing/selection |
| Tactical Empathy | Read scenario, write empathy statement (understanding ≠ agreement) | Demonstrate understanding at key emotional moments | Drill recognition → Simulate under pressure |
| Active Listening | Listen to 2-min monologue → Summarize (accuracy check) | Track content + emotion across 10-turn conversation | Drill comprehension → Simulate sustained attention |
| Accusation Audit | Read scenario → List negatives → Write audit | Deliver audit naturally in opening of tense conversation | Drill exhaustiveness → Simulate delivery timing |
| Affirmations (MI) | Read case → Identify strengths → Write affirmations | Spot and verbalize strengths in real-time conversation | Drill recognition → Simulate naturalness |
| Paraphrasing / Summarizing | Read statement → Paraphrase in own words | Summarize at key transition points in 10-turn conversation | Drill accuracy → Simulate timing |
| NVC Need | Given feeling → Identify underlying need | Express need naturally after stating feeling | Drill need vocabulary → Simulate integration |
| NVC Request | Given need → Formulate clear, doable request | Make request at appropriate moment without demanding tone | Drill clarity → Simulate delivery |
| De-escalation | Read escalation → Write de-escalation response | Lower intensity in live heated conversation | Drill language patterns → Simulate real-time regulation |
| Perspective-Taking | Read scenario → Write counterpart's view from their frame | Articulate opponent's perspective during negotiation | Drill accuracy → Simulate strategic use |

**Transfer insight:** Drill mastery predicts 60-70% of simulation performance, but drill-competent to simulation-fluent requires 10-20 simulation reps.

## Drill-to-Simulation Progression Model

```
Drill Mastery (Syntax + Recognition)
    ↓
Guided Simulation (Technique scaffolded/prompted)
    ↓
Free-Form Simulation (Technique not prompted, post-detection only)
    ↓
High-Stakes Simulation (Technique under time/emotional pressure)
    ↓
Transfer Assessment (Novel scenario, integrated techniques)
```

### How Drill Differs from Simulation

| Dimension | Skills Lab (Drill) | Simulation Studio |
|---|---|---|
| Cognitive load | Low (focus on ONE technique) | High (track conversation + apply multiple + manage emotion) |
| Time pressure | None (can think, revise, submit) | Real-time (must respond in 5-15 seconds) |
| Opponent unpredictability | Fixed prompt (same every time) | AI varies response based on user's moves |
| Emotional activation | Minimal (low stakes, hypothetical) | Moderate-high (feels like real conflict/negotiation) |
| Feedback timing | Immediate (after single response) | Delayed (post-session analysis) |
| Success criteria | Binary (syntax correct/incorrect) | Spectrum (technique used appropriately for context) |

**Key insight:** Drill success doesn't guarantee simulation success because context recognition (WHEN to use) and integration (combine with others) are separate skills that only develop through full-context practice.

## Drill Format Taxonomy

### Format 1: Prompt → Response (Text-Based)

**Best for:** Syntax-driven techniques (mirroring, labeling, open questions, "I" statements, NVC)

```
Prompt: "I can't believe you scheduled this meeting without asking me first."
Task: Write a labeling response.
User: "It sounds like you're frustrated that I didn't check with you."
Score: ✅ Syntax correct, emotion accurate
```

**Effectiveness:** High for building declarative knowledge (knowing the structure).

### Format 2: Audio Prompt → Spoken Response (with Prosody Feedback)

**Best for:** Vocal techniques (tonality control, FM DJ voice, strategic silence, de-escalation tone)

- Play audio scenario (angry voice, tense situation)
- User records spoken response (30-60 seconds)
- Hume.ai analyzes: pitch, pace, volume, arousal, valence
- Feedback: "Pace too fast (180 WPM, target 120-140), pitch too high"

**Effectiveness:** High for prosodic skill but requires 3-5x more user effort than text drills.

**When to use:** After text drill mastery, before live simulation.

### Format 3: Multiple-Choice Recognition

**Best for:** Building pattern recognition before production skill.

```
Scenario: Counterpart says "Your price is way too high."
Which is the best calibrated question?

A. "Why do you think that?" ❌ (Why-question, sounds defensive)
B. "Can you explain what you mean?" ❌ (Yes/no frame)
C. "How am I supposed to lower the price?" ✅ (Shifts problem-solving)
D. "What's your budget?" ❌ (Factual, not calibrated)
```

**Effectiveness:** Medium for knowledge, low for skill. Use as warm-up or assessment only.

### Format 4: Rewrite Exercise

**Best for:** Techniques with clear good/bad versions (open vs closed questions, "I" vs blame, judgment vs observation).

```
Original (aggressive): "Why didn't you tell me about this?"
Task: Rewrite as a calibrated question.
User: "How was I supposed to know about this?"
Score: ✅ Changed why → how, shifted responsibility
```

**Effectiveness:** High for error correction and building discrimination.

### Format 5: Spot-the-Technique (Transcript Analysis)

**Best for:** Building recognition of techniques in realistic conversation flow.

```
Transcript:
A: "I'm worried this project is going to fail."
B: "It sounds like you're feeling anxious about the outcome." ← LABEL
A: "Yeah, I don't think we have enough time."
B: "How much time do you think we need?" ← CALIBRATED QUESTION

Task: Identify all labels and calibrated questions.
```

**Effectiveness:** Medium for knowledge, helps bridge drill → simulation gap.

### Effectiveness Ranking by Technique Type

| Technique Type | Best Format | 2nd Best | Avoid |
|---|---|---|---|
| Syntax-driven (mirroring, labeling, open questions) | Prompt → Response | Rewrite | Multiple-choice only |
| Vocal/prosodic (FM DJ voice, tonality) | Audio → Spoken response | — | Text-only |
| Multi-turn integration ("That's right", Black Swan) | Simulation only | Spot-the-technique (prep) | Isolated drill |
| Recognition/judgment (perspective-taking, change talk ID) | Spot-the-technique | Multiple-choice | Prompt → Response |
| Error-prone patterns (yes/no questions, blame statements) | Rewrite exercise | Prompt → Response | — |

## Simulation Studio Scenario Taxonomy

### Multi-Dimensional Taxonomy (Not Single-Axis)

Each scenario tagged with 4 dimensions:

#### Dimension 1: Domain Context

| Domain | Example Scenarios |
|---|---|
| Workplace - Manager | Performance review, deadline negotiation, delegation |
| Workplace - Peer | Collaborative conflict, resource competition |
| Workplace - Customer | Complaint handling, upselling resistance |
| Personal - Relationship | Household conflict, family negotiation |
| Personal - Service | Contractor negotiation, medical conversation |
| Sales / Business Development | Pricing negotiation, objection handling |

**Why domain matters:** Context-specific practice improves real-world application 40-60% more than generic practice.

#### Dimension 2: Counterpart Disposition (Difficulty 1-5)

| Level | Behavior | Techniques Required | Unlock Logic |
|---|---|---|---|
| 1. Cooperative | Willing to talk, responsive, low hostility | Basic active listening, open questions | Tier 1 drills complete |
| 2. Hesitant | Guarded, noncommittal, needs drawing out | Labeling, tactical empathy, affirmations | Tier 2A drills complete |
| 3. Resistant | Pushback, objections, sustain talk | Rolling with resistance, calibrated questions, contrasting | Tier 2B drills complete |
| 4. Aggressive | Interrupts, accuses, emotionally escalated | De-escalation, accusation audit, strategic silence, FM DJ voice | Tier 3 mixed proficiency |
| 5. Deceptive / Strategic | Withholds info, misleads, tests boundaries | Black Swan discovery, "No" questions, perspective-taking | Tier 3 advanced mastery |

**Graduated difficulty (1→5) improves retention 30-50% vs random difficulty.**

#### Dimension 3: Technique Focus (Learning Objective)

| Focus Type | Description | When to Use |
|---|---|---|
| Single-technique | Scenario requires specific technique 3-5 times | Immediately after drill mastery (bridging) |
| Technique cluster | Scenario requires 2-3 related techniques | Tier progression (all Tier 2A techniques together) |
| Free-form | Goal but no requirements; post-analysis detects | Advanced integration, transfer assessment |
| Remedial | Targets user's diagnosed weakness | Adaptive recommendation engine feeds this |

#### Dimension 4: Conversational Goal

| Goal Type | Example Scenarios | Technique Emphasis |
|---|---|---|
| Information gathering | Salary research, customer discovery | Calibrated questions, tactical empathy, Black Swan discovery |
| Persuasion / Influence | Sales pitch, change management | Loss aversion framing, vision-building, change talk elicitation |
| Conflict resolution | Team disagreement, relationship repair | STATE, Three Conversations, NVC, de-escalation |
| Boundary setting | Saying no, confronting violation | Assertiveness, contrasting, "I" statements |
| Relationship building | Onboarding, trust-building | Active listening, affirmations, tactical empathy |

Difficulty: 3 (Resistant)
Focus: Technique cluster (Labeling + Calibrated Questions + Contrasting)
Goal: Conflict resolution

| Tier | Scenarios | Difficulty | Focus |
|---|---|---|---|

Per technique (Tier C): 2 scenarios (different domains, same difficulty)

### Comprehensive (Full Platform): ~110 Scenarios

Per technique: 4-6 scenarios (3+ domains, 2-3 difficulty levels)

Platform feels "complete" at ~100-120 unique scenarios.

### Scenario Reuse Logic

Same scenario, different focus:
- "Project Deadline Pushback" can be labeling-focused (Level 2), calibrated-questions-focused (Level 3), or free-form integration (Level 4)
- AI adapts counterpart behavior based on user's technique selection and tier level

**45 scenario templates × 3 focus variations = 135 distinct experiences from 45 base scenarios.**

## Guided vs. Scaffolded vs. Free-Form Simulations

### Research Comparison

| Approach | Benefits | Drawbacks | Best For |
|---|---|---|---|
| Guided (required) | Forces practice, builds automaticity, tracks compliance | Feels less natural, may use technique inappropriately | Early practice (Tier 1, 2A) |
| Scaffolded (suggested) | Balances guidance + autonomy, allows natural timing | — | Mid practice (Tier 2B, 3) |
| Free-form (detection only) | Feels realistic, tests true mastery | Harder for novices | Advanced practice (Tier 3, 4) |

### Progression by Tier

```
Tier 1 (Foundational):     → GUIDED (must use technique 3x)
Tier 2A (Reflective):      → SCAFFOLDED (suggested 2-3 uses, not required)
Tier 2B (Strategic):       → SCAFFOLDED → FREE-FORM (first 2 scaffolded, then free)
Tier 3-4 (Advanced/Expert): → FREE-FORM only (post-detection, no prompts)
```

**Guided → free-form progression improves real-world transfer 35-50% compared to guided-only or free-only.**

## Architecture Summary

| Dimension | Skills Lab | Simulation Studio |
|---|---|---|
| Purpose | Build syntax mastery + automaticity | Build timing, integration, pressure-testing |
| Techniques | Tier A (drills-first) + Tier C (drill basics) | Tier B (simulation-only) + Tier C (drill → sim progression) |
| Formats | Prompt→Response, Audio→Spoken, Rewrite, Spot-the-Technique | Multi-turn AI roleplay (guided → scaffolded → free-form) |
| Cognitive Load | Low (isolated focus) | High (multi-technique, real-time, emotional) |
| Feedback | Immediate, binary/spectrum | Delayed, post-session analysis |
| Unlock Logic | After tier prerequisite drills complete | After drill mastery in target technique |
| Beta Minimum | 5-10 drills per Tier A/C technique | 45 scenarios (2 per technique, tiered difficulty) |
| Comprehensive | 15-20 drills per technique | 110 scenarios (4-6 per technique, full matrix) |
| Progression | Drill → 90%+ accuracy → Unlock simulation | Guided → Scaffolded → Free-form |

**Architecture aligns with deliberate practice principles:** isolate → automate → integrate → transfer.

## KDENZ Platform Implications

1. **Generic drill engine is confirmed as the #1 build priority.** 10 Tier A techniques all use the same Prompt→Response→Score pattern. Build the engine once, configure per technique.

2. **5 drill formats, not 1.** Current labeling/audit modules only use Format 1 (Prompt→Response). Need to add Rewrite, Multiple-Choice, Spot-the-Technique, and Audio→Spoken. The drill engine must support format selection per technique.

3. **Simulation Studio has 3 modes, not 1.** Guided, Scaffolded, and Free-form are different UX flows. The simulation engine must track which mode to use based on user's tier level.

4. **45 base scenarios for beta, not 110.** Scenario reuse logic (same scenario × 3 focus variations) gives 135 distinct experiences from 45 templates. This is achievable.

5. **Scenario data model needs 4 dimensions.** Domain + Difficulty + Focus + Goal. Current `scenarios.ts` in labeling/audit only has category + difficulty. Need to extend.

6. **Drill → Simulation threshold is concrete.** Each Tier A technique has a specific rep count before simulation unlocks (e.g., 10 correct mirrors, 15 accurate labels). This feeds directly into the mastery system from R9.

7. **Audio drills (Format 2) require Hume integration.** Vocal Tonality Control and FM DJ Voice can't ship until Hume batch is integrated. This is Phase 2 of the build order (R8 analysis).

8. **Transfer gap is quantified.** Drill mastery predicts 60-70% of simulation performance. The remaining 30-40% requires 10-20 simulation reps. This informs the VCM diagnostic — if someone scores well in drills but poorly in simulation, it's a Gate E (action under pressure) issue, exactly matching R5's diagnostic rules.
