## Key Findings

### 1. Framework Overlap Identified

| CBT Technique | MI Equivalent |
|--------------|--------------|
| Socratic Questioning | Evocative Questions |
| Cognitive Restructuring | Reframing Reflections |
| Both use collaborative discovery vs. directive teaching | |

### 2. Integration with Voss Negotiation Techniques

| Voss Technique | CBT/MI Equivalent |
|---------------|-------------------|
| Labeling | Complex Reflection (MI) + Emotion Labeling (CBT) |
| Calibrated Questions | Socratic Questioning (CBT) + Evocative Questions (MI) |
| Mirroring | Simple Reflection (MI) |
| Accusation Audit | Normalizing (CBT/MI) + Amplified Reflection (MI) |

### 3. Prerequisite Pathway

```
Tier 1 (Foundation): MI OARS + CBT emotion regulation + assertiveness
    |
Tier 2 (Intermediate): MI change talk + CBT cognitive restructuring + Socratic questioning
    |
Tier 3 (Advanced): Voss tactical techniques
```

**Critical insight:** MI builds motivation (why bother?) -> CBT teaches skills (how to do it) -> Voss applies tactically (when to deploy). You can't teach labeling without teaching complex reflections first.

## Part 3: Integration Analysis

### Direct Overlaps

| Technique Pair | Implication |
|---------------|------------|
| Socratic Questioning (CBT) = Evocative Questions (MI) | Teach once, apply in both contexts |
| Cognitive Restructuring (CBT) = Reframing Reflections (MI) | Same skill, different framing |
| Assertiveness (CBT) = Emphasizing Autonomy (MI) | Complementary, not identical |
| Exposure Hierarchy (CBT) = Progressive difficulty (adaptive learning) | Already in your system architecture |
| Behavioral Rehearsal (CBT) = Skills Lab drills | Your drill engine IS behavioral rehearsal |

### How CBT and MI Complement Each Other

| Dimension | MI | CBT |
|-----------|-----|-----|
| Approach | Evocative (draw out) | Directive (teach/install) |
| Primary goal | Build motivation | Build skills |
| Best for | Pre-contemplation → Preparation | Preparation → Action |
| Risk | Too passive (never teaches) | Too directive (triggers resistance) |
| Integration | MI prevents defensiveness that CBT's directive approach might trigger |

### Mapping to VCM Gates

| Gate | Primary Framework | Rationale |
|------|------------------|-----------|
| A: Awareness | MI (pre-contemplation techniques) | Need to raise doubts, not push action |
| B: Desire | MI (decisional balance, values) | Motivation is MI's core competency |
| C: Belief | CBT (self-efficacy, cognitive restructuring) | CBT excels at changing beliefs |
| D: Intention | CBT (behavioral planning, if-then) | CBT's structured approach fits planning |
| E: Initiation | CBT (graded task assignment, behavioral experiments) | Behavioral activation is CBT territory |
| F: Persistence | Both (MI for motivation maintenance, CBT for habit formation) | Hybrid approach |
| G: Recovery | MI (normalizing, reframing) + CBT (reattribution) | Both contribute |
| H: Integration | MI (identity, values alignment) | MI's person-centered approach |

## KEY IMPLEMENTATION TAKEAWAYS FOR KDENZ

### After Overlap Removal with Existing Techniques:
- 89 total -> ~54 unique high-priority techniques (scores 4-5)
- ~35 distinct from existing Voss techniques after removing overlaps
- Combined with existing ~22 Voss/foundational techniques = ~57 total techniques for full platform

### Build Order Recommendation:
1. **OARS drills** — reuse labeling drill infrastructure (reflection drills are structurally identical)
2. **Recognition exercises** — "identify this technique in a transcript" (new drill format, high reuse)
3. **Change talk elicitation** — roleplay-dependent, build with Simulation Studio
4. **CBT cognitive techniques** — journaling/reflection format (new UI component needed)
5. **Values/decisional balance** — interactive exercises (new UI component needed)

### Critical Architecture Decision:
16 of the 23 score-5 MI techniques can reuse the existing labeling drill infrastructure (prompt -> response -> AI evaluation). Build a **generic drill engine** that parameterizes technique type, evaluation rubric, and feedback template.
