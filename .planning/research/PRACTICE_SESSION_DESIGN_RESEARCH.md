# Practice Session Design Research

**Created:** 2026-01-26
**Purpose:** Research-backed design principles for skill practice modules (Labeling, Accusation Audit, future modules)

---

## Executive Summary

Three research areas inform practice session design:

1. **Emotional Labeling Impact** - How labels affect people at different emotional depths
2. **Feedback System Design** - Best practices for practice tool feedback
3. **Scenario Realism** - Making practice feel real for skill transfer

---

## 1. EMOTIONAL LABELING IMPACT

### The Three-Tier Emotional Depth Model

| Level | What It Is | Example Label | Impact When Accurate |
|-------|-----------|---------------|---------------------|
| **Surface** | Observable/presented emotions | "Sounds like you're frustrated" | Relief, permission to continue |
| **Underlying Driver** | Hidden motivations beneath surface | "Seems like you feel disrespected" | "That's exactly right" - trust unlocked |
| **Core Identity** | Self-image, values, fundamental needs | "Your integrity is on the line" | Transformative - deep connection |

### Neurological Basis (Lieberman et al., UCLA)

- Accurate labeling reduces amygdala activation
- Increases prefrontal cortex engagement (regulatory control)
- Creates physiological calming effect
- Effect is automatic - doesn't require belief in its efficacy

**Key insight:** Accurate labeling literally helps the brain regulate itself.

### Context Modifiers

| Factor | Professional Context | Personal Context |
|--------|---------------------|------------------|
| Appropriate depth | Start Level 1, careful with Level 2 | Can move to Level 2 faster |
| Safe emotion categories | Frustration, concern, pressure | Fear, hurt, disappointment |
| Risk profile | Defensiveness damages working relationship | Inaccuracy damages intimacy |

### Power Dynamics

| Dynamic | Labeling Approach |
|---------|------------------|
| Superior → subordinate | Label the situation, not the person |
| Subordinate → superior | Tentative framing ("I might be wrong, but...") |
| Peer → peer | Most latitude for deeper labeling |

### Measurable Outcomes - Verbal Cues

**Gold Standard:** "That's exactly right" (Voss)
- Indicates Level 2 (underlying driver) accurately hit
- Often followed by elaboration and new information

| Response | What It Indicates | Depth Hit |
|----------|------------------|-----------|
| "That's exactly right" | Perfect accuracy on underlying driver | Level 2-3 |
| "Yes!" (emphatic) | Strong resonance | Level 1-2 |
| Elaboration/expansion | Trust unlocked, offering more | Level 2+ |
| Long pause before speaking | Processing deep accuracy | Level 2-3 |
| Softened voice/tone | Emotional regulation engaged | Level 2+ |
| Self-disclosure | Trust established | Level 2-3 |

**Defensive Indicators:**

| Response | What It Indicates | Recovery |
|----------|------------------|----------|
| "That's not what I said" | Mislabeling or too deep too fast | Retreat to surface |
| "Don't tell me how I feel" | Premature depth | Use softer framing |
| Crossed arms, leaning back | Physical defensiveness | Reset with acknowledgment |

### Depth Progression Path

```
1. Start with surface observations
   "It sounds like this has been frustrating"

2. When acknowledged, probe one level deeper
   "And underneath that, it seems like there's concern about being heard"

3. Only go to identity/needs when Level 2 is confirmed
   "It sounds like your credibility is really important here"

TIMING RULE: Wait for confirmation at each level before going deeper
"That's exactly right" = permission to go deeper
```

## 2. FEEDBACK SYSTEM DESIGN

### Core Principle: Mirror, Don't Judge

The most effective feedback acts as a **mirror** that helps learners see themselves clearly, not as a **judge** that evaluates them.

| Mirror Feedback | Judge Feedback |
|-----------------|----------------|
| "I noticed you used 'um' 12 times, mostly when you paused to think" | "You used too many filler words. Work on this." |
| "When you paraphrased their concern, they shared more" | "You scored 80 on empathy" |
| "Your labeling created a visible shift in their tone" | "Good job on active listening" |

### Impact Over Evaluation

| Evaluation Framing | Impact Framing |
|-------------------|----------------|
| "You interrupted 3 times" | "When you spoke over them, they became quieter" |
| "Your pace was too fast" | "At 180 WPM, key points may not land" |
| "Score: 73/100" | "Your filler rate dropped from 8/min to 5/min" |

### The Gap + Path Model

Effective feedback has two components:
1. **Gap**: Clear identification of current vs. desired state
2. **Path**: Actionable direction for improvement

```
BAD: "You used 12 filler words"

GOOD: "You used 12 filler words (vs 8 last session).
       Most occurred when transitioning between points.
       Experiment: Try pausing for 1 second instead of saying 'um'."
```

### Exploration Framing (Activates Growth Mindset)

| Avoid | Use Instead |
|-------|-------------|
| "Your score" | "Your session" |
| "Areas for improvement" | "Patterns to explore" |
| "You failed to..." | "Next experiment:" |
| "Correct" / "Incorrect" | "Observed" / "Target" |
| "Good job!" / "Needs work" | Neutral observation + trend |

### The Lab Mental Model

Framing practice as **experimentation** reduces performance anxiety.

- Use language: "experiment," "discover," "notice," "explore"
- Frame sessions as "experiments" not "tests"
- "What do you want to experiment with today?"
- Working title "VoiceLab" already supports this framing

### Faded Feedback Model

Start with immediate feedback, gradually reduce as skills develop:

```
Sessions 1-3: Real-time indicators visible always
Sessions 4-7: Summary mode (updates every 30 seconds)
Sessions 8+: Hidden during practice, shown only at end
User can always toggle back to real-time if desired
```

### When Scores Help vs Harm

| Helpful | Harmful |
|---------|---------|
| Compare to personal best | Compare to other users |
| Show trend lines (improvement over time) | Single-session scores in isolation |
| Qualitative levels ("Improving", "Steady") | Raw numerical scores without context |

## 3. SCENARIO REALISM

### The Key Insight: Psychological Fidelity > Physical Fidelity

Users don't need photorealistic graphics or perfect voice synthesis. They need:
- **Functional task alignment**: Cognitive demands match real situations
- **Emotional authenticity**: Stakes feel personally meaningful
- **Behavioral realism**: Conversation partner responds as a real person would

**Research finding:** Low-fidelity simulations with high psychological engagement outperform high-fidelity simulations with low engagement for skill transfer.

### Backstory Design (2-3 Sentences)

Optimal backstory answers:
- Who is this person to me?
- What is at stake?
- What just happened before this moment?

**Example:**
> "Your colleague Marcus has been dismissive of your ideas in meetings for months. You've just learned he's taking credit for your project proposal with the VP. You run into him at the coffee machine."

### Emotional Engagement Triggers

| Trigger | Effect |
|---------|--------|
| Personal relevance | "This is like YOUR difficult coworker" |
| Uncertainty | Not knowing how they'll react |
| Social evaluation threat | Feeling observed (even by AI) |
| Time pressure | Real-time response requirements |
| Escalation potential | Situation could get worse |

**Counter-intuitive:** Participants report higher realism when they feel *anxious*, not comfortable.

### AI Conversation Partner Realism

**The Uncanny Valley of Dialogue** - AI feels fake when:
- Too agreeable ("You're absolutely right")
- Too articulate (perfect grammar, no hesitation)
- Too fast (instant responses)
- Too predictable (same pattern every time)

**Realism Techniques:**

| Technique | Implementation |
|-----------|---------------|
| Response latency | 1-3 seconds before difficult responses |
| Disfluency patterns | "Look, I... it's not that I don't value your work..." |
| Emotional consistency | Defensive person stays defensive across turns |
| Memory callbacks | Reference something user said earlier |
| Emotional shifts | Emotions change during conversation, not static |

### When AI Should Push Back vs Accommodate

**The 70/30 Rule:** User should succeed ~70% of the time while facing genuine resistance ~30%.
- All success = no learning
- All failure = learned helplessness

**Push Back When:**
- User uses vague language
- User backs down too quickly
- User succeeds too easily
- Practice objective is boundary-setting

**Accommodate When:**
- User demonstrates genuine skill improvement
- Emotional overwhelm is apparent
- Building early confidence

### Progressive Difficulty Levels

1. **Recognition**: Identify the right approach
2. **Compliant Partner**: Practice with cooperative other
3. **Mild Resistance**: Partner pushes back politely
4. **Strong Resistance**: Partner is defensive/aggressive
5. **Complexity**: Multiple competing concerns, ambiguous right answer

### Avatar/Persona Design

**Minimum Viable Persona:**
- Name
- Relationship to user
- One dominant personality trait
- Current emotional state
- What they want from this conversation

**Key Principle:** Consistent personality traits across sessions. Users learn to read personality and adapt. Inconsistent personas produce confusion.

**User-Created vs System-Created:**

| Approach | Best For |
|----------|----------|
| System-created | Skill building, consistent quality |
| User-created | Real-situation preparation (higher anxiety, stronger transfer) |
| Hybrid | Templates user can customize |

### Skill Transfer Factors (Ranked by Effect Size)

1. **Contextual similarity**: Practice matches real environment
2. **Emotional intensity**: Includes stress, not just mechanics
3. **Variable practice**: Multiple scenarios, not just one repeated
4. **Reflection/debrief**: What worked, what to try differently
5. **Spacing**: Distributed practice over time (1-3 days between)
6. **Interleaving**: Mix scenario types for better retention

## 4. IMPLEMENTATION PRINCIPLES

### For Labeling/Accusation Audit Modules

**Replace Scoring with Affect:**

| Instead of | Show |
|------------|------|
| "Coverage Score: 75" | "Your label hit the underlying driver - this typically creates openness" |
| "Delivery: 80/100" | "When you acknowledged their concern first, they became less defensive" |
| "Grade: B+" | "Patterns to explore: pausing before the deeper label" |

**Feedback Structure:**
```
1. OBSERVATION (neutral)
   "You labeled their frustration, then probed for the underlying concern"

2. AFFECT (impact)
   "This type of progression typically creates trust because they feel heard before being understood"

3. RESPONSE QUALITY INDICATOR
   - "That's exactly right" equivalent = deep connection created
   - Elaboration = trust unlocked
   - Defensive response = calibration needed

4. PATTERN TO EXPLORE (micro-action)
   "Experiment: Add 2 seconds of silence after the label before continuing"
```

### For Unlimited Conversation Turns

- No artificial limits on conversation length
- Like basketball practice - shoot as long as you want
- Session ends when user chooses to end
- AI maintains persona consistency across all turns
- Each turn is a learning opportunity

### For Saved Avatars

**Core Features:**
- User can create and save personas
- Name, relationship, personality traits, emotional patterns
- Optional password protection for sensitive scenarios
- Personas persist across sessions
- Track practice history per persona

**Privacy Consideration:**
- Password-protected avatars stored locally (not synced)
- Unprotected avatars can be backed up
- Clear warning when creating sensitive scenarios

## Summary: Key Design Decisions

| Decision | Research Basis |
|----------|---------------|
| Show affect, not scores | Mirror vs Judge principle |
| Impact framing | Outcome-oriented feedback research |
| Unlimited turns | Basketball practice analogy - no artificial limits |
| Consistent personas | Personality consistency enables skill building |
| 2-3 sentence backstories | Optimal immersion without cognitive overload |
| AI response latency | Avoids uncanny valley |
| Progressive difficulty | Zone of Proximal Development |
| 70/30 success ratio | Optimal challenge for learning |
| Spaced practice | 1-3 days between sessions for consolidation |
| Post-practice reflection | Critical for skill transfer |
