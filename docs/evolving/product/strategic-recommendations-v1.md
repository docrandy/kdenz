## 1. MVP Feature Roadmap

### Phase 1: Core (MVP Launch)
- Recording + transcript + dashboard
- 4 core metrics: Pacing/WPM, Filler Words, Pause Patterns, Pitch Range
- Personal baseline (first session)
- Post-session review with playback
- Chrome-only

### Phase 2: Engagement
- Real-time feedback (pacing gauge, filler word alerts during recording)
- Progress tracking (trend charts across sessions)
- Scenario-based practice (interview Q&A prompts)
- Gamification (streaks, progress celebration -- no leaderboards)

### Phase 3: Differentiation
- Volitional diagnostics (3-5 question onboarding: skill gap vs motivation gap vs commitment gap)
- Implementation intentions (post-session "when/then" prompts)
- Coaching add-on (optional human check-ins)
- B2B team dashboard (if validated)

## 2. UX & Design Best Practices

### Metric Presentation
- Simplify for consumers: avoid jargon, use comparisons to self (not population)
- Time-series graphs for progress (before/after, trend lines)
- Dashboard flow: "How did I sound?" -> "What changed?" -> "What should I do next?"

### Onboarding
- Explain each metric before showing it
- First session = baseline (low-stakes, neutral topic)
- Frame as discovery, not assessment

### Gamification (Evidence-Based)
- **Use:** Streaks (12% engagement lift -- Duolingo data), progress charts, celebration of milestones
- **Avoid:** Global leaderboards, badges for everything, judgment language
- **Rule:** Personalized benchmarks (compare to own past), effort-based rewards (not outcome-based)
- Average retention lift from well-implemented gamification: 22%

### What Users Actually Value (from Research)
1. Progress visibility (seeing improvement over time)
2. Specific, actionable feedback (not just numbers)
3. Coaching context (not just "you used 6 fillers" but "here's when and why")
4. Control over what's measured and shown

## 3. Monetization Tiers

| Tier | Price | Features | Target |
|------|-------|----------|--------|
| **Free** | $0 | 1 recording/day, 3-4 basic metrics (pace, fillers), no trends | Build habit, lower friction |
| **Premium** | $10-15/mo | Unlimited recordings, all metrics, transcripts, trend charts, playback with highlights | Individual power users |
| **Coaching** | $50-100/mo | Premium + optional human coaching check-ins (you initially) | High-value users |
| **Team (B2B)** | $8-12/seat/mo | Premium + admin dashboard, team analytics | L&D departments |

**Target:** 20%+ free-to-premium conversion rate (Orai/Yoodli achieve this).

## 4. Go-To-Market Strategy

### Content Marketing (Primary Channel)
- Blog posts on interview tips, speaking confidence, filler word awareness
- Target keywords: "interview practice app", "filler words", "speech coaching"
- SEO-driven acquisition at <$5 CAC

### Partnerships
- Career coaching platforms
- Toastmasters chapters
- University career centers
- L&D consultants (for B2B)

### Referral
- "Practice with a friend" feature (compare sessions, not scores)
- Invite flow after "holy shit moment"

## 5. Success Metrics by Phase

### Phase 1 (MVP): Validation
| Metric | Target | Kill Criteria |
|--------|--------|--------------|
| Baseline completion rate | 60%+ | <40% |
| Week-1 retention | 40%+ | <20% |
| "Holy shit moment" rate | 50%+ report awareness surprise | <20% |
| NPS | 40+ | <20 |

### Phase 2 (Engagement): Retention
| Metric | Target | Kill Criteria |
|--------|--------|--------------|
| 30-day retention | 30%+ | <15% |
| Sessions per week (active users) | 2-3 | <1 |
| Premium conversion | 15%+ | <5% |
| Feature satisfaction (real-time feedback) | 4/5+ | <3/5 |

### Phase 3 (Differentiation): Revenue
| Metric | Target | Kill Criteria |
|--------|--------|--------------|
| Monthly recurring revenue | Growing 20%+ MoM | Flat or declining |
| Coaching tier adoption | 5-10% of premium users | <2% |
| B2B pilot interest | 3+ companies | Zero after 20 outreaches |
| Net revenue retention | 100%+ | <85% |
