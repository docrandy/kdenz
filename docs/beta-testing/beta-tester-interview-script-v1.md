# Beta Tester Interview Script

- **Tier:** Scoped (beta testing phase)
- **Status:** ACTIVE
- **Version:** v1
- **Source:** Original project file
- **Summary:** Interview script for validating core assumptions with 5-10 private beta testers after 3+ sessions.

---

**Purpose:** Validate core assumptions with 5-10 private beta testers
**When:** After testers have used VoiceLab at least 3 times

---

## Questions

### 1. Willingness to Pay
> "Would you pay $12.99-28.99/mo for a tool that helps you practice difficult conversations?"

**What we're validating:** Price sensitivity and perceived value at target price points

---

### 2. Messaging Test
> "Which message resonates more:"
> - A) "Train your voice like athletes train their bodies"
> - B) "You're smart. Your conversations should prove it."

**What we're validating:** Which positioning angle connects -- aspirational fitness vs intellectual identity

---

### 3. Pattern Recognition (Paywall Trigger)
> "After using this 3 times, what pattern did you notice?"

**What we're validating:** Whether users experience the "holy shit moment" -- discovering unconscious speaking habits. This is the paywall trigger hypothesis: awareness of a pattern = motivation to keep practicing.

---

### 4. Retention Blockers
> "What's stopping you from using this daily?"

**What we're validating:** Friction points, missing features, or UX issues that prevent habit formation
