# C0/C3 Boundary: Quick Reference Guide

**Purpose:** Rapid classification tool for practitioners
**Use:** When you need to quickly determine if a constraint is C0 (Environmental Friction) or C3 (Heteronomous Action)

---

## The One-Question Test

**"Does this compromise the agent's reasons-responsiveness and second-order volitions?"**

- **NO** → C0 (Environmental Friction)
- **YES** → C3 (Heteronomous Action)

---

## The Five-Question Protocol

When the one-question test is unclear, use all five:

### Q1: SOURCE
**"Is this imposed by another agent with intent to control behavior?"**
- NO → Points to C0
- YES → Points to C3

### Q2: MECHANISM
**"Does this affect what I CAN do (execution) or what I WANT to do (my will)?"**
- CAN do → Points to C0
- WANT to do → Points to C3

### Q3: REASONS-RESPONSIVENESS
**"If the reasons for this changed, would I respond differently?"**
- YES → Points to C0
- NO → Points to C3

### Q4: AUTONOMY
**"Do I feel I'm CHOOSING this, or do I feel I HAVE TO?"**
- Choosing → Points to C0
- Have to → Points to C3

### Q5: WILL-OVERBEARING
**"Does this make options less attractive, or override my will?"**
- Less attractive → Points to C0
- Override will → Points to C3

**Decision:** 3+ questions pointing the same direction = classification

---

## Quick Classification Patterns

### Clear C0 Patterns

✓ Physical obstacle (locked door, broken equipment)
✓ Resource constraint (no money, no time, no energy)
✓ Natural condition (weather, darkness, terrain)
✓ Psychological friction (anxiety, fatigue, mild discomfort)
✓ Internalized norm I genuinely value

**Key:** Makes action harder but doesn't change what I want to want

---

### Clear C3 Patterns

✓ Boss demand / authority command
✓ Coercive threat ("do X or else")
✓ Strong social pressure (ostracism threat)
✓ Trauma response (freeze, fawn)
✓ External norm I resent but must follow

**Key:** Shapes my will, creates desires I don't endorse

---

## Common Boundary Cases

### Internalized Norms
**Test:** "If the external pressure disappeared, would I still do this?"
- YES → C0 (internalized, autonomous)
- NO → C3 (still external pressure)

### Social Pressure
**Test:** "Can I genuinely refuse without it overriding my will?"
- YES → C0 (mild social influence)
- NO → C3 (social coercion)

### Professional Standards
**Test:** "Do I value this, or just comply to avoid judgment?"
- Value this → C0 (internalized)
- Avoid judgment → C3 (external pressure)

### Trauma Response
**If past trauma triggers automatic response:**
- Classification: C3-derived (historical C3, current trigger)
- Rationale: Compromises will despite no current controller

## Decision Tree

```
START: What's the constraint?

│
├─ Is it imposed by another agent with control intent?
│  │
│  ├─ NO → Probably C0 (but check other criteria)
│  │  └─ Confirm: Does agent remain reasons-responsive?
│  │     ├─ YES → C0
│  │     └─ NO → Check for trauma (C3-derived)
│  │
│  └─ YES → Probably C3 (but check internalization)
│     └─ Confirm: Does agent willingly endorse this?
│        ├─ YES → Check: Would maintain if pressure gone?
│        │  ├─ YES → C0 (internalized)
│        │  └─ NO → C3 (still external)
│        └─ NO → C3
│
└─ RESULT: C0 or C3 (or C3-derived for trauma)
```

## Red Flags for C3

Watch for these indicators that suggest C3 despite surface appearance:

⚠ "I have to" language (not "I choose to")
⚠ Feels compelled despite wanting something else
⚠ Would stop immediately if external pressure disappeared
⚠ Deliberation is bypassed ("I don't even think about it, just comply")
⚠ Conflict between what agent does and what they value

---

## Green Flags for C0

These indicators suggest C0 even if obstacle is frustrating:

✓ "This is difficult but it's my choice"
✓ Can deliberate about alternatives
✓ Would maintain behavior even if obstacle removed (for internalized norms)
✓ Feels aligned with own values despite difficulty
✓ Can explain reasoning in terms of own goals

## Example Classifications

### Example: Locked Door
- Source: Not agent-imposed → C0
- Mechanism: Affects execution only → C0
- Reasons-responsive: Yes → C0
- Autonomy: Choosing to leave → C0
- Will-overbearing: No → C0
**RESULT: Clear C0**

### Example: Boss Threat
- Source: Boss with control intent → C3
- Mechanism: Creates unwanted desire → C3
- Reasons-responsive: Compliance overrides → C3
- Autonomy: Feel compelled → C3
- Will-overbearing: Yes → C3
**RESULT: Clear C3**

### Example: Professional Dress Code
- Source: Originally external → Check internalization
- Test: "Would I dress professionally anyway?"
  - YES → C0 (I value professionalism)
  - NO → C3 (Only to avoid judgment)
**RESULT: Context-dependent**

### Example: Freeze Response to Authority
- Source: No current agent, but past trauma → C3-derived
- Mechanism: Affects will (don't want to freeze) → C3-derived
- Reasons-responsive: No (automatic) → C3-derived
- Autonomy: Not endorsed → C3-derived
- Will-overbearing: Yes (overrides will) → C3-derived
**RESULT: C3-derived (special category)**

## When to Use Full 5-Criterion Analysis

Use the comprehensive protocol when:
- Initial classification is unclear
- Source and autonomy conflict (external but feels autonomous)
- Internalized norms with uncertain endorsement
- Social pressure with ambiguous intensity
- Any case where 1-question test doesn't give clear answer

---

## Common Mistakes to Avoid

**Mistake 1: "External = C3"**
- ✗ WRONG: All external constraints are C3
- ✓ CORRECT: Internalized external norms can be C0

**Mistake 2: "Internal = C0"**
- ✗ WRONG: All internal states are C0
- ✓ CORRECT: Trauma responses are C3-derived despite being internal

**Mistake 3: "Difficult = C3"**
- ✗ WRONG: If it's hard, it must be C3
- ✓ CORRECT: C0 can be very difficult; test is will-formation, not difficulty

**Mistake 4: "Agent says 'choosing' = C0"**
- ✗ WRONG: Trust self-report alone
- ✓ CORRECT: Check reasons-responsiveness and will-overbearing objectively

**Mistake 5: "No person visible = C0"**
- ✗ WRONG: If no person in the room, it's C0
- ✓ CORRECT: Authority/social pressure can be C3 even when person is absent (threat still active)

## Practitioner Tips

**Tip 1: Start with source, but don't stop there**
- Source is a good initial filter
- But always check at least 2-3 other criteria
- Especially important for internalized norms

**Tip 2: Weight reasons-responsiveness heavily**
- This is the most reliable objective test
- Less susceptible to rationalization than autonomy experience
- If reasons-responsiveness is clearly compromised → likely C3

**Tip 3: Look for second-order conflict**
- Does agent want something but also want NOT to want it?
- This is classic sign of C3 (unwilling addict pattern)
- Example: "I comply but I wish I didn't care what they think"

**Tip 4: Use the disappearance test**
- "If [external pressure] disappeared, would you still do this?"
- Reliable test for internalization vs external pressure
- If answer is immediate "no" → likely C3

**Tip 5: When in doubt, check all 5 criteria**
- If first impression is unclear, be systematic
- Document which criteria point which direction
- Mixed results = genuinely ambiguous, note context

## Confidence Levels

**High Confidence Cases (Classify Immediately)**
- Physical obstacles → C0
- Resource constraints → C0
- Natural conditions → C0
- Authority commands → C3
- Coercive threats → C3

**Medium Confidence Cases (Check 3+ Criteria)**
- Internalized norms
- Social pressure
- Professional standards
- Institutional requirements

**Low Confidence Cases (Use Full Protocol)**
- Trauma responses (consider C3-derived)
- Internalized oppression
- Systemic constraints
- Cultural norms with unclear endorsement

---

## Special Categories

### C3-Derived (Trauma/Conditioning)
**When to use:**
- Clear historical origin in external control (trauma, abuse)
- Current circumstantial trigger (no active controller)
- Still compromises will and reasons-responsiveness

**Examples:**
- Freeze response to authority figures
- Fawn response to social situations
- Conditioned fear from past abuse

**Classification rationale:** Not pure C0 (affects will) or pure C3 (no current controller), but originated in C3 and still compromises autonomy.

---

## Key Definitions

**C0 (Environmental Friction):**
Obstacles that preserve second-order volitions and reasons-responsiveness. Agent willingly endorses action despite execution difficulty.

**C3 (Heteronomous Action):**
External demands that compromise second-order volitions and reasons-responsiveness. Agent's will is shaped by external control, not their own deliberation.

**Second-order volition:**
What you want to want. Your desires about your desires. Your values about your values.

**Reasons-responsiveness:**
Ability to recognize and respond to reasons. Deliberation isn't bypassed or overridden.

**Will-overbearing:**
Not just making options less attractive, but actually overriding the will. Creating options "no reasonable person could refuse."
