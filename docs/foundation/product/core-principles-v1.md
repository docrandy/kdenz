# Core Principles for Non-Clinical Voice Coaching

- **Tier:** Foundation
- **Status:** LOCKED
- **Version:** v1
- **Source:** Claim-Safe Copy Library and SaaS Action Plan (original docx)
- **Summary:** Five non-negotiable principles that govern all product behavior, feedback, and data handling.

---

## Principles

1. **Be descriptive, not diagnostic:** Report observable measurements (counts, rates, ranges), not mental states.

2. **Anchor to user's own baseline:** Avoid population comparisons unless justified with group-specific performance data.

3. **Show uncertainty:** Include confidence intervals / error margins and surface failure modes (noise, accents, etc.).

4. **Bias is expected -- measure it, report it, mitigate it:** Especially for non-native speakers, women/high-pitch speakers, older users, and neurodivergent users.

5. **Give users control:** Opt-out, granular toggles, deletion controls, and a "dispute/feedback" path.
